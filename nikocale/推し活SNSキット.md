# ニコカレ 推し活SNSキット

> アプリの外（TikTok / Instagram / X の投稿・ハッシュタグ）で「推し活」を仕掛けるための運用メモ。
> アプリ本体はメイン（二人の相性）に集中させ、推し活はSNS投稿で広げる方針。
> 最終更新: 2026-09-29

---

## ① ハッシュタグ（コピペ用）

**基本セット**
```
#ニコカレ #相性診断 #運命の日
```

**推し活で足す**
```
#推しとの相性 #推し活 #推しの誕生日 #相性占い #誕生日占い #四柱推命
```

- X / TikTok は 3〜5個、Instagram は 10個前後まで足してOK。
- 投稿の内容に合うタグだけ選ぶ（無関係な大量タグは逆効果）。

---

## ② 投稿テンプレ（そのまま貼れる）

### X（Twitter）
```
推しの誕生日で相性チェックしたら"奇跡の相性日"出てきて叫んだ🫨
生年月日だけで本格鑑定できるの神。あなたも→[URL]
#ニコカレ #推しとの相性 #運命の日
```

### Instagram（キャプション）
```
#推し活 の新定番。
推しとあなたの"運命の日"、本格鑑定でわかる🔮
ストーリーズにも貼れる縦画像つき📱→[URL]
#ニコカレ #推しとの相性 #相性診断 #運命の日
```

### TikTok（動画ネタ＋キャプション）
- **ネタ**：画面録画で「推しの誕生日を入力 → 相性カレンダーが出る → 奇跡の日にリアクション」。テロップ：*推しとの相性、本格鑑定でやってみた*
- **キャプション**：
```
推しとの相性やってみて🥹 当たってたら保存
#推しとの相性 #ニコカレ #運命の日
```

---

## ③ バズりやすいコンテンツの型

1. **「推しとの相性やってみた」リアクション動画**（TikTok / Reels）← 一番伸びやすい
2. **「◯月、推しと相性がいい日ランキング」** ＝ ストーリーズ用の縦画像（9:16）を貼る
3. **「あなたの干支キャラ診断」** ＝ キャラ主役の共有画像で自己紹介系
4. **参加型**「あなたの推しの誕生日教えて → 相性みるよ」でコメント誘発

---

## ④ 使える素材（アプリから出せるもの）

- **共有画像（4:5）**：フィード投稿向け。キャラ主役・ローズ配色。
- **ストーリーズ用画像（9:16・📱ボタン）**：インスタ/TikTokのストーリーズにフル画面で収まる。
- **共有テキスト（自動付与）**：「ふたりの"運命の日"、本格鑑定でわかった あなたも無料でチェック→ #ニコカレ #相性診断 #運命の日」

---

## ⑤ 1つだけ注意（誠実さ・炎上回避）

- 推しの **誕生日（公開情報）を使うのはOK**。
- ただし有名人の **写真・名前で"公式"を装う投稿はNG**（なりすまし・誤認を招く）。
- あくまで **「ファンが楽しんでいる」トーン**で出すと、炎上せず好感度も上がる。

---

## ⑥ 運用のコツ

- まずは **TikTokのリアクション動画**を軸に（一番拡散しやすい）。
- 投稿は **[URL] を必ず入れる**（プロフィールのリンクにも固定）。
- 反応が良かったタグ・型を見つけたら **同じ型を量産**する。
- 「無料」「登録なしで試せる」を必ず添える（若者の心理的ハードルを下げる）。
