# にこカレ 相性ごよみ ロジック仕様書（確定版）

- 対象：`nikocale/index.html` の相性カレンダー（二人の「良い日／避けたい日」判定）
- 位置づけ：**この文書がにこカレのカレンダー・ロジックの正本**。四柱推命エンジン（`engine.js` / `daily-engine.js` / インライン `PersonBazi`）は土台（166unmei / 運気予報）と同一で**改変禁止**。本書はその上に載る「二人・日別合成」ロジックを記述する。
- 最終更新：2026-09-15（「両者好調」加味を反映）

---

## 0. 全体像

にこカレのカレンダーは、四柱推命の確定ロジックを土台に、次の2つを**日別・二人分に合成**して「その日が二人にとって良いか／避けたいか」を出す。

1. **相性（harmony）**＝その日の干支が、二人それぞれの日柱とどれだけ調和するか（§2）
2. **個人運（pa/pb）**＝二人それぞれの、その日の個人日運グレード 💮◎〇△（§3）

目的（デート／告白／勝負／仲直り／友達）ごとに合成式を変え（§4）、閾値でマーク（◎○△×）を付ける（§5）。

> 実装：`nikocale/index.html` の `rel()` / `daily()` / `evalDay()`。

## 2. 相性（harmony）— その日と二人の関係

`rel(day, per)` が、その日の干支（`day`）と個人の日柱（`per`）の関係を素点化する。

**カレンダー専用の素点表（相性診断の総合スコア §5 とは別物。日別の増減用に負値を持つ）**

```
天干 ST = {干合:+6, 干相生:+3, 干比和:+2, 干相剋:-2}
地支 BR = {支合:+8, 三合:+6, 同:+3, 支相生:+4, 支比和:+2,
          破:-3, 害:-4, 刑:-6, 沖:-8, 支相剋:-2}
```

- 各人の素点 `sc = ST[天干関係] + BR[地支関係]`
- **harmony = cA.sc + cB.sc**（二人の合計）
- あわせて関係フラグを保持：`chong(沖)` `kei(刑)` `hai(害)`

---

## 3. 個人運（pa / pb）

各人のその日の個人日運グレードを数値化（`GV`）。

```
GV = { 💮:+2, ◎:+1, 〇:0, △:-1 }
pa = GV[Aの個人日運], pb = GV[Bの個人日運]
```

個人日運は `daily()`→`KD.generateDaily(..., {personBazi})` で算出（§6の相対評価。喜神/忌神・流年流月補正込み）。

---

## 4. 目的別スコア式

```
romance = Σ(干合なら+3, 支合なら+3)   // 二人分
help    = Σ(支合/支相生/三合なら+2)    // 二人分
mood    = (pa + pb) * 2               // 両者の個人運（範囲 -4〜+8）★2026-09追加

デート・友達 : score = harmony + mood
告白         : score = harmony + romance （pa<0で-4, pb<0で-4）
勝負         : score = round(harmony*0.5) + (pa+pb)*4   // 個人運が主役
仲直り       : score = harmony + help + mood
```

### 設計方針
- **相性(harmony)が主役**。個人運は「押し上げ／控えめ」の補正に留める（デート・友達・仲直り）。
- **勝負**は「各自の勝負運」が主役なので個人運を×4で強く効かせ、相性は半減。
- **告白**はときめき（干合/支合）を加点しつつ、どちらかが不調(△)なら減点。

---

## 5. マーク判定（順序厳守）

`evalDay()` 内。**上から順に評価**する。

```
1. 沖（cA/cB のどちらかが沖）        → ×「避けたい」   ※score無関係で最優先
2. 仲直りかつ非沖かつ(刑または害)   → △「注意」       ※仲直り限定の緩和
3. score >= 11                       → ◎「特に良い」
4. score >= 4                        → ○「良い」
5. score < 0                         → △「注意」
6. それ以外(0〜3)                    → マーク無し「ふつう」
```

- **⭐（二人の運命が動く日）**＝その月の◎のうち、score 上位3日。
- **× は「沖」のみ**。刑・害・破は△以下に留める（きつく出しすぎない方針）。桃花（モテ星）は日支に対し刑/破になるため、沖のみ×にすることでモテ日が×にならない。

---

## 6. 「両者好調」加味の担保（2026-09 変更の意図）

- 変更前：デート／友達／仲直りは `harmony` のみ＝**二人が個人的に不調でも相性が良ければ◎**になっていた。
- 変更後：`mood=(pa+pb)*2` を加算し、**二人とも好調なら押し上げ／二人とも不調なら控えめ**に。
- **相性は主役のまま**：◎（score≥11）到達には harmony が最低でも軽くプラス＋両者好調が必要。相性の悪い日が個人運だけで◎になることはない。
- **沖は不変**：両者好調でも沖の日は×。

## 7. 検証（独立Nodeエンジン ＋ 実UIで確認済み）

テスト：A=1990/5/15(女)・B=1992/8/20(男)、2026年9月、目的=デート。

- デート：◎ **10 → 14**。両者が個人的に◎/💮の日（**5・15・18・29日**）が◎に昇格。10日は両者◎で △→・ に緩和。
- ⭐運命が動く日：**8・11・16日 → 8・11・20日**（20日＝二人とも💮＋支合で本命日入り）。
- 避けたい日：**9・21日（沖）は不変**。
- ページエラーなし。UI表示とNode独立計算が一致。

> 検証方法：`engine.js`＋`daily-engine.js`＋インライン`PersonBazi`をNodeで読み込み、`evalDay`を同一ロジックで再実装して全日を計算 → 実ブラウザ（Playwright）でカレンダーを描画し突合。
