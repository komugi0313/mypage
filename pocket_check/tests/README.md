# 命式エンジン検証テスト

`meishiki_standalone.html`（エンジン内蔵版）の四柱推命の計算を、
**独立した数式・別ロジック**で答え合わせする回帰テストです。

## 実行方法
Playwright（Chromium）が必要です。
```
node tests/verify_engine.js    # 日柱/十神/月柱/時柱/年柱/空亡/蔵干/恋愛table
node tests/verify_engine2.js   # 大運の順行逆行/節入り/立運/干合table
```

## 検証内容と「答え」の出どころ（独立性）
| 層 | 独立した検算方法 |
|---|---|
| 日柱 | ユリウス通日(JDN)から算出（甲子=2000/1/7基準） |
| 日柱の連続性 | 40年ぶん毎日、60干支が1つずつ・断絶なく巡るか |
| 十神 | アプリの tenGodOf() と、エンジンが別途出す tenStar の突合 |
| 月柱 | 五虎遁ルール（年干→月干） |
| 時柱 | 五鼠遁ルール（日干→時干） |
| 年柱 | 甲子=1984 の絶対位相（立春後） |
| 空亡 | 日柱の旬空 |
| 蔵干(本気) | 標準table |
| 大運 順行/逆行 | 年干陰陽×性別 |
| 節入り | 各節の代表日で月支が一致するか |

全テスト合格を確認済み（最終実行時）。
既知の注意：節入り直前（数分差）生まれの立運は境界ケースとして
アプリが「要確認」と明示し、手計算での確認を促します。

## 蔵干の完全検証（資料6「月律分野蔵干表」との突合）
`node tests/verify_zoukan.js`
- 12支すべての蔵干（余気・中気・正気）の**干と比率(%)**が表と一致するか
- **★司令（当令）**が「節入り後の経過日数（setsuMin）」で表の区切りどおりに
  選ばれているか（7,000件超で本質的な不一致ゼロを確認済み）

## 変通星の完全検証（資料5「変通星」表との突合）
`node tests/verify_tsuhen.js`
- アプリの tenGodOf() を、資料5の表の**全100通り（日干10×相手干10）**と照合
- エンジンの tenStar も、実命式に現れる全100種類の (日干×柱干) で表と照合
- いずれも不一致ゼロを確認済み

## 十二運星の完全検証（資料5「十二運星」表との突合）
`node tests/verify_juniun.js`
- 日干×地支→十二運（terrain）を、資料5の表と**全120通り（日干10×地支12）**照合
- この表は火土同法（戊=丙・己=丁）。エンジンも同convention＝不一致ゼロを確認済み

## 吉凶星(2)の検証（資料5④・日柱干支ベース）
`node tests/verify_kichi.js`
- 魁罡（庚辰庚戌壬辰壬戌戊戌）・禄馬貴人（壬午癸巳）・日刃（丙午戊午壬子）を
  60日柱すべてで照合＝検出漏れ・誤検出ゼロを確認済み
- ※魁罡日は renderSolo で必ず詳細カードを出力（kaigouCard）

## 合の検証（資料5⑧「合」表との突合）
`node tests/verify_gou.js`
- アプリの干合(GANGOU)5組・六合(RIKUGOU)6組が表と一致
- エンジンの natalRelationsX（六合/三合/半会/方合）を、表から独立計算した
  期待値と全命式で照合＝検出漏れ・余分な検出ゼロ（三合4局・方合4局・六合）

## 大運の割り出し（資料(2)）
`node tests/verify_daeun.js`
- 順行/逆行＝年干陰陽×性別（488件）＝一致
- 第一運＝月柱（488件）＝一致
- 大運の干支列＝月柱±k（60甲子を順行/逆行、3904件）＝完全一致（表の核心）
- 立運＝日数÷3：方法は同じ。ただしエンジンは節入りを時・分まで精密計算するため、
  整数日の手計算と月数が1〜2ヶ月ずれることがある（境界では年が1年ずれる場合も）。
  年はほぼ一致。節境界生まれはアプリが「要確認」と明示済み。

## 吉凶星(3)の検証（資料5⑤・月支ベース）

## 吉凶星(4)の検証（資料5⑥・年支/日支ベース）

- 隔角（年→日）も表どおり＝一致

## 刑冲破害の検証（資料5⑦との突合）
`node tests/verify_keichuha.js`

- 5940命式で検出漏れ・余分な検出ゼロ＝完全一致
