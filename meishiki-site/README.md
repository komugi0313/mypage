# MEISHIKI株式会社 コーポレートサイト

Webサービス開発会社としての「ロジカル・知的・クリーン」な印象と、占い師「水木にこ」の
「親しみやすさ」を両立させた、簡易コーポレートサイトです。静的HTML/CSSのみで動作します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（理念・2事業の概要・料金抜粋・代表メッセージ導入） |
| `services.html` | 事業紹介（メイン：Web開発／サブ：占い鑑定＋ロジック解説） |
| `company.html` | 会社概要・代表挨拶（後藤理恵＝水木にこを繋ぐプロフィール） |
| `contact.html` | 予約・お問い合わせ（鑑定予約／開発依頼の切替フォーム） |
| `style.css` | 共通スタイル（薄紫×ピンクのブランドカラー） |

## サイトマップ（二面性を一枚で見せる構成）

```
MEISHIKI Inc.
│
├─ ホーム (index.html)            … 「水木にこ」の世界観を前面に、IT企業としての理念
│    ├ ヒーロー：占い × テクノロジー
│    ├ 理念（Logical / Technology / Trust）
│    ├ 2事業（Main：Web開発  ／  Sub：占い鑑定）
│    ├ 料金抜粋
│    └ 代表メッセージ導入 → company.html へ
│
├─ 事業紹介 (services.html)
│    ├ Main：自社Webサービス／占いロジックのシステム化／制作受注
│    ├ 占いを「システム」にする3ステップ（ロジック解説）
│    ├ Sub：占い鑑定（四柱推命・易経・手相・姓名判断・九星）
│    └ 鑑定料金
│
├─ 会社概要・代表挨拶 (company.html)   … 法的信頼性の担保ゾーン
│    ├ 代表挨拶（後藤理恵 ＝ 水木にこ／顔写真）
│    ├ 「水木にこ」と「後藤理恵」の関係の説明
│    └ 会社概要テーブル（社名・代表・所在地・連絡先・SNS）
│
└─ 予約・お問い合わせ (contact.html)
     ├ タブ切替フォーム（🔮鑑定予約 ／ 💻開発・制作依頼）
     └ 直接連絡先（事務所電話・仕事用携帯・メール・SNS）
```

### 「名前」の扱い方針（重要）
- **サイト全体の主役は「水木にこ」**。トップ〜事業紹介はこの活動名で世界観を統一。
- **代表者名「後藤理恵」と顔写真は `company.html` のみ**に掲載し、企業としての法的信頼性を担保。
- 会社概要ページで「同一人物」であることを、母ミチコ・社名の由来とともに自然な物語として接続。

## 差し替えが必要な箇所

- ロゴ画像（現状はCSSで「M」マークを表現。実ロゴ画像に差し替え可）
- 代表写真：`company.html` の `.photo` 内コメント部分に `<img src="goto-rie.jpg">` を設置
- 住所・電話番号・メール・SNS（Instagram / TikTok）の各 `#` リンクとプレースホルダ
- 料金は税込/税抜の表記をご確認のうえ確定してください
- お問い合わせフォームの送信先（現状はデモ動作。Formspree等の設定が必要）

## プレビュー方法

```
cd meishiki-site
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
