- キーは環境変数 `GEMINI_API_KEY` から読むだけです。ファイル・zip・ログには書きません。
- 実行：`GEMINI_API_KEY` を設定した環境で `bash tools/live_ai_test/run.sh`
- 結果：`tools/live_ai_test/out/`（pro.json / beg.json / eki.json と画面の写真）。`out/` は git に入れません。
