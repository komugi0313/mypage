# 16タイプの人物像 執筆ガイド

## どこで使うか
16TYPE+ の結果画面で、「今のあなた」（60問の診断や、自分で選んだ16タイプ）の人物像として読む文章。同じ文章を「生まれつきのあなた（本来の自分）」の説明にも使う。16Personalities の結果ページのように、読んで「これ私だ」と思える、具体的で読みごたえのある人物像にする。

## サイトの考え方（必ず守る）
- 目的は、生きづらさを感じている人に、仕事や人間関係が少し楽になるヒントを渡すこと。面白さだけが目的ではない。
- どのタイプも悪く聞こえない、中立で前向きな言葉にする。弱点は「つまずきやすいところ」として、責めずに、理由と一緒に書く。
- 専門用語は使わない（四柱推命の用語、心理学の専門用語も避ける）。「MBTI」という言葉は使わない。16Personalities のタイプ名（建築家・運動家など）や、その文章・言い回しを真似しない。オリジナルの文章で書く。
- 性別・年齢を決めつけない。恋人は「恋人」「好きな人」「パートナー」。学生にも社会人にも当てはまる場面を混ぜる。
- 文体：です・ます調。やわらかく、読みやすく、1文は短め。

## 各タイプの呼び名（サイト独自。冒頭で使ってよい）
INTJ 話す前に結論出てるタイプ／INTP 気づけば検索沼タイプ／ENTJ じゃあ私が決めるタイプ／ENTP 逆にさ、が口ぐせタイプ／INFJ 言わなくても気づくタイプ／INFP 頭の中が映画館タイプ／ENFJ つい世話やいちゃうタイプ／ENFP ときめき最優先タイプ／ISTJ 締切より早く出すタイプ／ISFJ 気づいたら動いてるタイプ／ESTJ まず予定表つくるタイプ／ESFJ 気づけば幹事タイプ／ISTP 説明より先に触るタイプ／ISFP 好き！で選ぶタイプ／ESTP 考える前に動いてるタイプ／ESFP ノリで決めちゃうタイプ

## 書くもの（1タイプにつき、JSON のキー）
```json
"ENFP": {
  "catch": "一言でいうと（20〜35字）",
  "overview": "概要（250〜350字）。どんな人か、何に動かされるか、まわりからどう見えるか。",
  "strengths": ["強み1（見出し8〜15字）｜説明40〜70字", "…", "…", "…"],
  "pitfalls": ["つまずきやすいところ1（見出し8〜15字）｜なぜそうなるか＋どうすると楽か 50〜80字", "…", "…"],
  "relationships": "人間関係（150〜220字）。友だち・職場での姿、相性のいい付き合い方。",
  "love": "恋愛（150〜220字）。好きになり方、大事にすること、すれ違いやすい点。",
  "work": "仕事（150〜220字）。力が出る環境、評価されやすい役割、疲れやすい環境。",
  "jobs": ["向いている仕事の例を5つ"],
  "growth": "成長のヒント（120〜180字）。今日からできる具体的な行動を1〜2つ入れる。",
  "A": "自己主張型（A）のときの特徴（80〜120字）。同じタイプの中での違い。",
  "T": "慎重型（T）のときの特徴（80〜120字）。同じタイプの中での違い。前向きに。"
}
```
- strengths と pitfalls は「見出し｜説明」の形で、全角の縦線「｜」で区切る。
- 4つの指標の意味：E 外向型（人と関わって元気になる）／I 内向型（ひとりの時間で元気になる）／S 現実型（事実や経験を頼りにする）／N 直感型（ひらめきや可能性を頼りにする）／T 思考型（筋道を立てて決める）／F 感情型（気持ちを大切にして決める）／J 計画型（見通しを立てて進める）／P 柔軟型（状況に合わせて柔軟に動く）。
- 16タイプどうしで言い回しが重ならないようにする。具体的な場面（LINE、会議、休日、旅行、買い物、部活・職場など）を入れる。
