# 16TYPE+ 組み合わせ文章（256通り）執筆ガイド

## サイトの考え方
- 16TYPE+ は「生まれつきのタイプ」（生年月日から出る、一生変わらない本当の自分）と、「今のタイプ」（16タイプ診断の結果。環境や経験で後から身についた自分）を比べる性格診断。
- サイトの目的は「本当の自分って何だろう」を見つけてもらうこと。**生まれつき＝本当のあなた**、**今＝環境の中で身につけた（がんばって適応した）あなた**として書く。
- 読み手は日本の10代後半〜40代。若い人にも大人にも刺さる、軽くて読みやすい言葉。

## 1組み合わせに書くもの（キーは「生まれつき>今」 例 "ISTJ>ISFJ"）
```json
"ISTJ>ISFJ": {
  "name": "やさしい顔した几帳面さん",
  "atari": ["…", "…"],
  "karai": "…"
}
```
- **name**（組み合わせの呼び名）：8〜16字。SNSのプロフィールに書きたくなる、くすっと笑える呼び名。悪口にはしない。
- **atari**（当たってる一文）×2：各30〜55字。生まれつき（本当の自分）と今のズレから出る、具体的な行動や心の動き。「本当は〜なのに、今は〜」「〜しながら、心の中では〜」の形が基本だが、毎回同じ書き出しにしない。場面は職場・学校・友だち・恋愛・LINE・家・お金・休日などから選び、具体的に。
- **karai**（辛口の一文）：30〜55字。図星を突かれて笑ってしまう本音。きついけれど悪口・人格否定にはしない。読んだ人が「やめて、当たってる」と思うライン。

## 生まれつきと今が同じ組み合わせ（例 "ISTJ>ISTJ"）
- 「生まれつきのまま生きている人」として書く。ブレない強み、裏表のなさ、そのぶん頑固・融通がきかない等の辛口。

## 4つの指標の意味（文章の材料）
- E（外向型）：人と関わって充電する／I（内向型）：ひとりの時間で充電する
- S（現実型）：事実・経験・具体を信じる／N（直感型）：ひらめき・可能性・全体像を見る
- T（思考型）：筋・論理で決める／F（感情型）：気持ち・共感で決める
- J（計画型）：予定を決めて進む／P（柔軟型）：流れに合わせて動く
- 変わった指標が、その組み合わせの「ズレ」の中心。例：生まれつきT→今F なら「本当は理屈で決めたいのに、今は空気を読んで合わせている」。変わった指標が複数あるときは、いちばん面白いズレを選ぶか、組み合わせて書く。

## 各タイプの呼び名（サイト内で使っているもの）
INTJ 話す前に結論出てるタイプ／INTP 気づけば検索沼タイプ／ENTJ じゃあ私が決めるタイプ／ENTP 逆にさ、が口ぐせタイプ／INFJ 言わなくても気づくタイプ／INFP 頭の中が映画館タイプ／ENFJ つい世話やいちゃうタイプ／ENFP ときめき最優先タイプ／ISTJ 締切より早く出すタイプ／ISFJ 気づいたら動いてるタイプ／ESTJ まず予定表つくるタイプ／ESFJ 気づけば幹事タイプ／ISTP 説明より先に触るタイプ／ISFP 好き！で選ぶタイプ／ESTP 考える前に動いてるタイプ／ESFP ノリで決めちゃうタイプ

## 書き方のルール
- 専門用語は使わない（四柱推命・干支・十二運などは書かない）。「MBTI」という言葉も使わない。16Personalities のタイプ名（建築家・運動家など）も使わない。
- 文字の英字（ENFPなど）は文中で使ってよいが、多用しない。
- 256通りすべて、言い回しが重ならないようにする。同じ書き出し・同じ場面を何度も使わない。
- 性別・年齢を決めつけない。恋人は「恋人」「好きな人」など。
- です・ます調ではなく、言い切りの短い文（例：「〜している。」「〜しがち。」「〜だったりする。」）。
- 例（質の目安）
  - "ISTJ>ISFJ" atari：「頼まれると笑顔で引き受けるのに、心の中では『それ、手順書ある？』と思っている。」
  - "ISTJ>ISFJ" karai：「やさしい人と言われるけど、ルールを守らない人のことは静かに一生覚えている。」
