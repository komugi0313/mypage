# 16TYPE+（16タイププラス）サイトの考え方

作り手が話した、このサイトの目的と方針のまとめ。文章やデザインを変えるときは、ここに立ち返る。

## なぜ作るのか
- 人は、自分でも気づかないうちに、環境・経験・過去の出来事によって考え方が変わっていく。だから「本来の姿」と「今生きている姿」にはギャップがある。
- 16タイプ診断が人気なのは、人が何かのカテゴリーにはまり、「自分はこういう人間だ」と理解したいから。けれど16タイプの結果は、そのときの気持ちやあいまいな答えでブレる。
- では、持って生まれたものは何か。それを生年月日（四柱推命）から出すのが「本当の自分」。16タイプの結果は「今の自分」。
- 生きづらさを感じている人ほど、本来の自分とのギャップが大きいのではないか。そのギャップが少しでも縮まれば、仕事や人間関係が楽になるはず。**このサイトは、そのヒントを渡すためのもの**。面白さだけが目的ではない。

## 方針
- **無料で出す診断**。目的は人を呼ぶこと（集客）。
- **日本向けが基本**。英語版・韓国語版も作るが、主役は日本。
- 名前は **16TYPE+（16タイププラス）**。ドメインは 16typeplus.jp。「MBTI」はサービス名・ロゴ・ドメインに使わない。16Personalities のタイプ名（主人公・運動家など）は、みんなが覚えている名前なので「ENFJ（主人公）」のようにカッコで添え、出典はページ下の注意書きで1回だけ説明する（自分のサイトの呼び名としては名乗らない）。イラストは使わない。
- 四柱推命は計算の中で使い、**画面には専門用語を一切出さない**（干支・十二運・通変星などは書かない）。
- 呼び方は **「生まれつき（本当の自分）」と「今の自分」**。「外の顔／中身」という言い方はしない（どちらの自分にも外の顔と中身があるため）。
- 2つのタイプを掛け合わせた新しい人物像は出さない。見せるのは **2つの差** と、そこから見える **悩み・ほどき方・仕事のヒント**。
- 言葉はどちらのタイプも悪く聞こえない、中立で前向きな表現にする（例：柔軟型＝「状況に合わせて柔軟に動く」）。辛口のひと言は、図星で笑えるが悪口にはしないライン。

## UI のルール
- **読みやすさ最優先**。白ベースで落ち着いた見た目（ネオンはやめた）。かわいさは相棒キャラ（60体の水彩キャラ）が担う。
- **泣き別れ（不自然な改行）を出さない**。日本語は文節で改行する（BudouX ＋ `word-break: keep-all`）。短い言葉や2行に分けた説明は、行ごとに改行させない。
- 何を表しているかが一瞬で分からない表現は使わない（例：黒いタイル、意味の分からない矢印だけの表示）。結果画面の「点線のタイル＝生まれつき、色付きのタイル＝今」を、ほかの場所でも同じ意味で使う。
- 広がる仕掛けは **相性（あの人に送るリンク）** と **相棒の今日のひと言**。
