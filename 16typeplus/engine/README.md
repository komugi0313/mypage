# 生まれつきタイプ計算の試作

- `bazi.js`：Pocket鑑定の四柱推命エンジン（節入り対応）。`window.PersonBazi(年,月,日,時,分,時刻不明,性別)`
- `model.js` ＋ `model2.js`（A案）：通変星の性質で4つの文字を点数化し、各指標が半々になるよう中央値で補正。
- `model3.js`（B案）：指標ごとに材料を分ける（E/I＝星の流れ、S/N＝土金と木水、T/F＝金水・寒と木火・暖、J/P＝正の星と偏の星）。
- 試し方：`node model2.js`（A案の2人の結果と、50年分のタイプの出方を表示）

答え合わせの例（16Personalities などで出た今のタイプ）：`node eval.js` で両案を比較できる
- 2008-03-28：INFP（最近 ENFP になることも）
- 1981-06-10：INFJ（たまに変わるが主にこれ）
- 2006-06-07：INFP
- 2007-09-18：ENFP
- 1981-07-30：ISTP
- 2006-05-27：ENFP
- 2007-11-01：INFJ（-A と -T は変わることがある）
- 2007-10-11：ENTP
- 2007-05-20：ISFP（以前 ESTP）
- 2007-09-07：ESFP（調整後に追加。調整に使っていない人で試すと ESTP、4文字中3文字一致）

8人での結果：A案 18/32文字、B案 16/32文字（どちらも偶然と大差ない）

## 自動調整の結果（9人）
- `node fit.js`：四柱推命の意味と逆向きにはしない・16タイプの出方が偏りすぎない、という条件つきで星の寄せ方を探す。結果は `fitted.json`。
- 9人への当たり：揺れない文字 27/33（ギャップ基準2を入れると 29/33、4文字すべて一致 6/9）。16タイプは最少でも3.4%出る。
- ただし「1人ずつ外して、残り8人で調整してから外した1人を当てる」確認では 15/33 で、当てずっぽうと同じ。
  → 9人分では、命式から16タイプの結果を当てる力はまだ確かめられない。人数を増やして確かめる必要がある。

- 2008-01-15：INFJ-A（A/T が分かっている人。身強/身弱の計算では T＝外れ）
- 2007-11-12：INTJ
