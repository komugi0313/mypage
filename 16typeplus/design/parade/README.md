# キャラクターパレード（横に流れる列）

16体のキャラクターが、横にゆっくり流れ続ける部品です。採用予定なので、単体で保存しています。

- `parade.html` … 見本。ブラウザで開くとそのまま動きます（絵は `characters/web/` のものを使用）
- 仕組み：同じ並びを2回つなげて、全体を半分だけ横に動かすと、つなぎ目なく流れ続けます
- 速さ：CSS の `animation:parade 70s` の秒数（大きいほどゆっくり）
- 絵の大きさ：`.ptrack img` の幅と高さ（今は 100×100）
- 動きを減らす設定の人には自動で止まり、指で横にスクロールできます
- マウスを乗せると一時停止します

使う絵は `characters/web/◯◯◯◯_s.webp`（240×240、高さをそろえた正方形）です。
