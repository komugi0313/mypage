# Claude Codeへの指示

このリポジトリの `index.html` と `src/` を読み込み、そのまま既存サイトへ統合してください。

絶対条件:
1. `src/assets` 内の画像を再生成・描き直し・加工しない。
2. 色、余白、フォント、カード形状、セクション順を変更しない。
3. 360 / 375 / 390 / 430 / 768 / 1024 / 1440pxで表示確認する。
4. AIという単語を画面へ追加しない。
5. LGBTQ+専用、四柱推命、易経、自己診断、相性診断、対話式の読み解きを維持する。
6. `prisma.html` のリンク先のみ実際の診断URLへ変更する。
7. 既存CSSで `h1`, `img`, `header`, `a`, `button` が上書きされないようスコープする。
8. 画像が存在しないとは言わず、このリポジトリ内のパスを使用する。
9. セキュリティ表現は「プライバシーを最優先に設計」とする。
10. デザイン改善や独自アレンジは禁止。
