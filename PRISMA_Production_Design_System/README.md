# PRISMA Production Design System

GitHubへこのフォルダの中身をそのままアップロードしてください。

## 最初に確認
- `index.html` をブラウザで開くとLPを確認できます。
- 診断開始リンクは現在 `prisma.html` です。実際のURLへ変更してください。
- AIという語は画面に表示していません。
- 四柱推命・易経・東洋占術・LGBTQ+専用を明記しています。

## 重要
`person.webp` は生成済み完成デザインから切り出した近似透過素材です。
元のレイヤー付き画像ではないため、髪の細部には淡い背景が残る場合があります。
完全一致を優先する箇所では `hero-desktop.webp` / `hero-mobile.webp` を一枚画像として使ってください。
