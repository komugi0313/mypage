## やること（この順番で）

### ① サイトのファイルを置きかえる。ただし、本番の設定3つは戻す

ZIPの中身は「完成形」です。ただし、**本番用の設定が空**になっています。置きかえたあと、次の3つを**今の本番と同じ値**に戻してください。戻さないと、登録・ログインが動きません。

| ファイル | 戻す値 |
|---|---|
| `login.html`・`register.html`・`mypage.html`・`unsubscribe.html` | `window.UNKIYOHO_AUTH_API_BASE = "";` → 本番のAPIのURL |
| `register.html` | 登録フォームの項目番号 `entry.1010` 〜 `entry.9999`（仮の番号）→ 本番の番号。紹介コードの `entry.1212` も |
| `mypage.html` | `window.UNKIYOHO_MY_REF` → 会員ごとの紹介コード |

### ② 2つのサイトは、同じタイミングで反映する

1.66 の中の「今日の運勢（体験）」は、`https://unkiyoho.jp/my-tenki-demo.html` を開きます。開運予報が古いままだと、1.66 の中に古い画面が出ます。

### ③ 毎朝のメールの「配信のしくみ」側も、同じファイルに置きかえる

サイトとは別に、配信のしくみ側でも、開運予報のZIPの中の次のファイルに置きかえてください。**ここを置きかえないと、メールは古いままです。**

- `daily-engine.js`
- `bazi.js`
- `jp-holidays.js`
- `engine.js`
- `mail-template/` フォルダごと（`render-daily-mail.js` が入っています）

呼び出し方は今まで通りです。注意は2つだけです。
- 配信日は**日本時間の日付**で渡す（UTCだと干支が1日ずれます）。
- `personBazi: PersonBazi` を必ず渡す。

置きかえたら、次を実行して **PASS** になることを確認してください。
```
cd mail-template && ENGINE_DIR=.. node check-quality.js
```

## 絵（画像）について

### メールの中の絵
- メールの絵は、メールに入れず、**サイトに置いた画像を読みに行く**作りです。
  - 読みに行く先：`https://unkiyoho.jp/mail-bg/…`（`renderDailyMail` の `assetBase: 'https://unkiyoho.jp/'` から決まります）
- なので、開運予報のZIPの `mail-bg/` フォルダを、**unkiyoho.jp に必ず置いてください**。
  - `banner-01.gif`〜`banner-12.gif`：月ごとの季節の絵（メールの一番上）
  - **`banner-12b.gif`：新しく増えた絵**（12/26〜12/31だけ使う、年末の絵）
  - `crystal-30.png`・`sr-166.jpg`・`sr-nicocale.jpg`・`sr-pocket.jpg`：メールの中の小さな絵・バナー
- 確認方法：ブラウザで `https://unkiyoho.jp/mail-bg/banner-12b.gif` を開いて、絵が出ればOKです。

### トップページの絵（サイトだけで使う。配信には関係なし）
- `hero-lucky-2026-10.webp`〜`hero-lucky-2031-12.webp`（63枚）：メール見本の左の画像。年月ごとに自動で選ばれます
- `hero-body-01.webp`〜`hero-body-12.webp`：メール見本の右の画像
- `lpcal/` フォルダ：トップのカレンダー見本（2026年10月〜2031年12月）
- `lp-detail.webp`：「マークの見かた」の画像
- **消してよいもの**：`hero-lucky-01.webp`〜`hero-lucky-12.webp`（年が入っていない古い12枚。もう使いません）

## 公開前の確認（5つだけ）

1. 登録 → 確認コードがメールで届く（画面に確認コードが出たら、①の設定が戻っていません）
2. テスト配信のメールに「💼 仕事運アップ」「🌈 大吉日」と出る（「勝負運アップ」「ご縁がいちばん高まる日」なら、③が古いままです）
3. メールの一番上に、その月の季節の絵が出る
4. 1.66 で、登録していない状態で5回診断すると、5回目に登録のお願いが出る
5. 1.66 の「今日の運勢（体験）」を開くと、ローズ色のボタンの新しい画面が出る（オレンジなら、開運予報が古いままです）
