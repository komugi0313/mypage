# 【エンジニアさんへ】開運予報の新しいアイコンへの入れかえ（11月25日 オーナー決定）

私だけの開運予報（kaiunyoho.com）のアイコンを、新しい「朝焼けの日の出」のアイコンに入れかえます。**今の海から太陽が昇るアイコンを使っているところは、すべてこの新しいアイコンにしてください。**

## 1. 上書きする画像（`画像（このまま上書き）` フォルダ）
同じ名前のファイルを、kaiunyoho.com のいちばん上（`index.html` と同じ場所）に上書きしてください。

| ファイル | 大きさ | 使われるところ |
|---|---|---|
| `favicon.ico` | 16・32・48px（1つのファイルの中に3つ） | ブラウザのタブ・Googleの検索結果 |
| `favicon-32.png` | 32px | ブラウザのタブ |
| `favicon-16.png`・`favicon-48.png` | 16px・48px | 予備（使っていれば上書き） |
| `app-icon-192.png` | 192px | Androidのホーム画面・Googleの検索結果 |
| `app-icon-512.png` | 512px | `manifest.webmanifest` の大きいアイコン |
| `app-icon-180.png` | 180px | iPhoneのホーム画面（`apple-touch-icon`） |
| `apple-touch-icon.png` | 180px | 同じ画像です。この名前を使っているページがあれば上書き |
| `icon-sun.png` | 96px（角を丸めたもの） | 上の帯の「マイページ」ボタンの中の小さなアイコン |

- HTMLの `<link rel="icon">` などは、今と同じファイル名なので、書きかえは要りません。
- `manifest.webmanifest` の `icons` に、ほかのファイル名（例：`icon-512.png`）が書いてあれば、そのファイルも新しいアイコンにしてください（大きい元の画像：`元の画像（大きいもの）.webp`）。
- 登録・ログイン・マイページ・配信停止・体験ページなど、**すべてのページ**で同じ画像を使っているはずです。ほかの名前の古いアイコン画像を使っているページがあれば、教えてください。

## 2. 入れかえたあと
- ブラウザやスマホは、古いアイコンを覚えていることがあります。新しいアイコンが出ないときは、ページを開き直す（キャッシュを消す）と変わります。
- iPhone・Androidのホーム画面にもう追加している人は、追加し直すまで古いアイコンのままです。
- Googleの検索結果のアイコンは、Googleがサイトを読み直したあとに変わります（数日〜数週間かかることがあります）。Search Consoleで、トップページの「インデックス登録をリクエスト」をしてもらうと、早く変わりやすいです。

## 3. 変えないもの
- カレンダーの印の絵文字（🌈 🌷 🌸 💼 🍀 ⚠️ 🌀 など）と ◎ ○ △、Googleカレンダーの予定は、今までどおりです。
- 画面やメールの中の「🌤️」の絵文字は、そのままです（オーナー決定）。

見本：`見本_新しいアイコンの見え方.png`
