## 応募ページに出す文（ユーザー向け）

### Nicoの鑑定が、毎月2名さまに当たります
公式LINE「Nicoの開運サロン」のお友だち限定。
当選した方は、Nicoの **オンライン鑑定（約30分）** を受けられます。料金はかかりません。

### 応募できる方
- 公式LINE「Nicoの開運サロン」のお友だち
- 年齢の制限はありません
- **18歳未満の方は、保護者の方の同意が必要です**
- 下の「応募の条件」すべてに同意いただける方

### 応募の条件（すべてに同意いただいた方のみ応募できます）
1. **お送りする「鑑定書」を、ご自身のSNSでシェアしてください。**
   鑑定のあと、Nicoから「鑑定書」の画像をお送りします（お名前・生年月日は入りません。年齢・性別だけです）。
   鑑定を受けてから **7日以内** に、X・Instagram・TikTok・Threads のいずれかで、
   **鑑定書の画像そのまま** と **ひとこと感想** に、次のハッシュタグをつけて投稿してください。
   **#PR #Nicoの開運サロン #私だけの開運予報 #奇跡の相性診断 #四柱推命**
2. **Nicoの公式SNSでも、鑑定の内容をご紹介します。**
   出すのは **年齢と性別だけ** です（例：「32歳・女性」）。
   お名前・お顔・生年月日・お住まいは **一切出しません**。
3. **ご本人とわからないように、内容は少しぼかして書きます。**
   お仕事・ご家族・お相手などの具体的なことは、特定されない形に変えて紹介します。
   ご自身で投稿するときも、同じようにぼかして書いてください。
4. **鑑定のあとに、感想をお聞かせください。**
   「当たっていたこと」「その後どうなったか」などを、LINEで教えてください。
   いただいた感想は、上の 2・3 と同じルールで紹介させていただくことがあります。

### 応募のしかた
- 公式LINEのメニュー「鑑定に応募する」から、次のことを送ってください。
  - ニックネーム
  - 生年月日（わかれば生まれた時間も）
  - 年齢・性別
  - 相談したいこと（ある程度くわしく）
- いただいた内容をもとに、Nicoが鑑定の準備をします。
- 応募は毎月 末日しめ切り。1人1か月1回まで。
- 相談の内容によっては、お受けできない場合があります。

### 抽選と当選のご連絡
- 毎月 5日ごろ に抽選し、当選した方にだけ **公式LINEのトークでご連絡** します。
- 7日以内 にお返事がない場合は、当選を取り消して、別の方に連絡します。
- 当選の発表は、ご連絡をもって代えさせていただきます。

### 鑑定について

## 運営メモ（ユーザーには出さない）
- **「#PR」が必要な理由**：鑑定を無料で受けた人に、運営側からお願いして投稿してもらうため、
  ステマ規制（2023年10月〜・景品表示法）の「広告」にあたる。投稿には「#PR」など
  広告とわかる表示が必要。つけ忘れると運営側の責任になるので、当選連絡のときに
  投稿のお手本（ハッシュタグ入り）を一緒に送る。
- **投稿してくれなかった場合**：鑑定のあとで無理に投稿させることはできない。
  1回目はやさしく催促し、それでも投稿がなければ、次回からの応募をお断りする程度にする。
- **感想を紹介するとき**：公式SNSでも「無料鑑定に当選した方の感想です」と一言そえる。
- **紹介する前に、ご本人に文面を確認してもらう**と、トラブルを防げる（おすすめ）。
- **プライバシーポリシーに書き足す**：公式LINEで受け取る情報（LINEの表示名・応募内容）と、
  その使いみち（抽選・連絡・鑑定・匿名でのSNS紹介）。18歳未満の方は保護者の同意が必要なことも書く。
- **抽選は懸賞のルールの範囲内**：商品の購入などが条件ではない「オープン懸賞」なので、
  景品の金額の上限はない。

## ハッシュタグのメモ
- **必ずつける（5つ）**：#PR #Nicoの開運サロン #私だけの開運予報 #奇跡の相性診断 #四柱推命
- **つけてもよい**：#占い #当たる占い #鑑定 #イッテンロクロク #開運
- 「#1.66奇跡の相性診断」は使えない。ハッシュタグは「.」で切れて「#1」になってしまうため、#奇跡の相性診断 にする。
- 「#開運予報」は、ほかの占いの投稿と混ざりやすい。サービス名どおり #私だけの開運予報 にする。
- #Nicoの開運サロン は、当選者の投稿を探して集めるための専用のタグ。毎回必ずつけてもらう。
- X は日本語140文字までなので、タグは5つまでにおさえる。

## 鑑定書と感想の運用メモ
- **鑑定書はSNSに載せる前提で作る**：お名前・生年月日・具体的な人名や会社名は入れない。
  「32歳・女性」とタイプのキャラ、Nicoのロゴ、鑑定のポイント3つ程度、画面の下に「#PR」とハッシュタグを入れる。
  X・Instagramで見やすい縦長（4:5）や正方形の画像にする。
- **感想の中身を「良いことを書いて」と指定するのはNG**：#PR の投稿は会社の広告あつかいになるので、
  会社が中身を指示して良い感想だけを書かせると、実際以上に良く見せる表示（景品表示法の優良誤認）になるおそれがある。
  お願いできるのは「鑑定書を載せる・ハッシュタグをつける・ひとこと感想を書く」まで。
- **変な感想を防ぐ方法（中身の指定ではなく、ルールと質で防ぐ）**
  - 投稿のお手本をそえる：「Nicoさんに鑑定してもらいました。ひとこと感想：＿＿＿」の形で渡すと、書く内容が短くまとまる。
  - 投稿のマナーとして、次の3つだけは書かないようお願いする（中身の良し悪しではなく、マナーの範囲）：
    ①ほかの人の個人情報 ②人を傷つける言葉 ③「必ず叶う」「100%当たる」のような言い切り
  - 鑑定の最後の5分で「いちばん心に残ったこと」を一緒に確認しておくと、感想がそこから書かれやすい。
  - 応募の相談内容を見て、30分の鑑定で応えられる相談の人を選ぶ（抽選の前の確認として、ルールに「相談内容によってはお受けできない場合があります」と入れておく）。
- **もし合わない感想が出たら**：消してもらうよう求めたり、言い返したりはしない。
  いろいろな感想があるほうが、かえって「本物の感想」として信用されやすい。
  公式SNSで紹介する感想は、運営が選んでよい（その場合も「個人の感想です」とそえる）。
