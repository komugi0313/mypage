# 【文章の書きかえ】相性診断の結果を、心に響く文章に

11/7 オーナーと相談して方向を決めた（丁卯の恋愛の書きかえ案で「これで良い」）。まだ実装はしない。

## なぜ書きかえるか（オーナーの言葉から）
- 今の文章は悪くないが、当たり障りがなく、教科書どおりで、読みがいがない
- 読んだ人が「なるほど」「面白い」「次はこうしてみよう」「頑張ろう」と思えないと、読んでもらえない
- リリースして間もない今が、直すチャンス

## 書き方の決まり
1. **「あるある」の場面から入る**：特徴を説明せず、その人がしていそうな場面を書く（例：告白の言葉を頭の中で何度も練習して、結局言えずに帰る）
2. **本音を言い当てる**：「本当は〜」「実は〜」で、まわりに見せていない気持ちを書く
3. **弱いところは、長所の裏返しとして書く**：責めずに、わかってあげる書き方
4. **最後に、小さな一歩を1つだけ**：今日からできること（例：1回でダメでも、もう1回だけ伝えてみて）
5. **話しかけるような言葉**：短い文で、かしこまらない。「〜を築きます」「〜が魅力です」のような教科書の言い回しは使わない
6. **「好きな人がこのタイプなら」も書く**：相性診断なので、相手の攻め方がいちばん読まれる
7. 言い切りすぎない（「〜しやすい」「〜なことが多い」）。不安をあおらない

使わない言葉は今までどおり（無料・最強・恋が動く日・60通りに1通り など）。

## 見本（丁卯＝空気読み検定1級タイプの恋愛）
**自分がこのタイプのとき**
> 好きな人ができると、頭の中では何度も告白しているのに、いざとなると言葉が出ない…そんな「もじもじ屋さん」なところがあります。一度断られると、もうダメだと閉じこもってしまいがち。でも、あなたのいちばんの魅力は、一度好きになったら、ずっとその人を想い続けられる一途さです。1回でうまくいかなくても、そこで終わりにしないで。時間をかけて伝えるほど、あなたのやさしさは、ちゃんと相手に届きます。

**好きな人がこのタイプのとき**
> この人は、気持ちを伝えられても、すぐには答えを出せないタイプ。嫌なわけではなく、頭の中でいろいろ考えすぎているだけのことが多いんです。1回で答えが出なくても、あせらずに、まっすぐな気持ちをもう一度伝えてみてください。心が動いたら、誰よりも一途に想い返してくれる人です。

## 書きかえる文章の量（11/7 数えたもの）
- 60タイプ × 恋愛の文（KOI・koi2）
- 60タイプ × 9つの欄（強み・気をつけたいこと・仕事・友だち・恋愛のつづき・うれしい一言・回復のしかた・傷つく一言・その理由）
- 二人の関係の種類ごとの、くわしい説明 14種類（はじめに・出会い・恋人になったら・友だち家族・活かし方・気をつけたいこと・ケンカしたら・長続きのヒント）
- 結果の本文・お祝いのポップアップの文 など

## 進め方（ミスを起こさないために）
1. 文章の一覧表を作る（どの場面で出るか／今の文／新しい文）→ オーナーが読んで確かめる
2. 入れかえるのは文字だけ。どの組み合わせでどの文が出るか、点数、タイプの決まり方には一切さわらない
3. 入れかえたら、全3,600組で「点数・結果の種類・選ばれる文の場所」が前と同じで、文字だけが変わったことを機械で確かめる。画面の幅で、はみ出しや変な改行がないかも見る
4. 一度に全部変えず、少しずつ出す

## 順番（おすすめ）
1. 60タイプの恋愛の文（自分がこのタイプ／好きな人がこのタイプ）
2. 二人の関係の本文（律音・干合など、結果の種類ごと）
3. くわしい説明（出会い・恋人になったら・ケンカしたら など）

## 作り方
オーナーが実際に見てきた人の姿（丁卯の「もじもじ屋さん」のような話）を、タイプごとに少しずつ聞かせてもらい、それと図鑑の内容をもとに下書きを作る。

## 11/8 決まったこと（癸酉・十二運 病）
- **短い文**：相手のことは全部お見通し。だからこそ、なかなか心を許せない慎重派。
- **つづきの文**：好きな人の小さな言葉のちがいや、表情の変化に、すぐ気づいてしまうタイプ。見えすぎるぶん、「本当に大丈夫かな」と心配ごとがふくらんで、なかなか一歩を踏み出せないことも。でも、一度心を許したら、一気に距離が縮まるのがこのタイプ。完璧な人を探すより、小さな約束をきちんと守ってくれる人を、信じてみて。

- **戊辰・この人を好きになったら**（146字）：どっしりとした安心感があり、まわりから自然と頼られる人。いつも相手を守ろうとするぶん、自分の弱さはなかなか見せません。ときには「あなたがいてくれて安心した」と、その存在の大きさを言葉にして伝えてみてください。純粋で、人を信じる気持ちが強い人なので、寄せられた信頼には、深い愛情で応える人です。
- **乙亥・この人を好きになったら**（150字）：おだやかで、人の気持ちにそっと寄りそえる人。にぎやかな場所より、落ち着いた時間や自分の好きな世界を大切にしています。心にふれたいなら、その好きなものに本当に興味を持つこと。すすめてくれた本や音楽を、実際に手に取ってみる。世界をわかち合える相手だと感じたとき、この人の心の扉は、静かにひらいていきます。
- **己卯・この人を好きになったら**（154字）：好きな人の喜ぶ顔が、何よりうれしい人。小さなプレゼントや気づかいに、愛情をこめています。ただ、先回りして頑張りすぎ、ひとりで抱え込むことも。してもらったことには、具体的な感想を添えて返すこと。選んでくれたお菓子なら、どこがおいしかったかまで。気持ちが届いたと感じたとき、この人はようやくほっとひと息つけます。
- **庚辰・この人を好きになったら**（152字）：落ち着いて品があるのに、胸の奥には大きな夢と熱い想いを秘めた人。何でもこなせるぶん、弱音を見せられる相手が少ないところも。挑戦がうまくいかなかった日は、アドバイスより先に、ここまで取り組んできた努力を認めること。当たり前と思われがちな頑張りを見てくれる人は、この人にとって、かけがえのない存在になります。
- **辛巳・この人を好きになったら**（148字）：品があって冷静で、何でもきちんとこなす人。感情を顔に出さないぶん、何を考えているかわかりにくいところも。でも心を許した相手には、意外なほど無邪気な一面を見せます。めずらしく冗談や小さな失敗を話してくれたら、一緒に笑って聞くこと。隙を見せても受け入れてもらえた安心が、この人の心をほどいていきます。
- **乙酉・この人を好きになったら**（150字）：上品で、細かいところまで気を配れる人。落ち着いて見えて、内側では人の目をとても気にしています。好きな人の前ほどきちんとしすぎるのは、意識しているサインかもしれません。小さな失敗は、人前ではさらりと流し、ふたりきりで笑って受けとめること。気をはらずにいられる相手こそ、この人がいちばん心を許せる人です。
