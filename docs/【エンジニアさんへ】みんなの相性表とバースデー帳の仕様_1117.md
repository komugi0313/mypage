## 1. 全体の流れ
1. 誘う人：トップで自分の生年月日を入れる → お相手の欄で「わからない」→「LINEで誘う」か「いま一緒にいる人と（QR）」
2. グループ（部屋）ができる。LINEのリンク、またはQR＋4けたの番号で参加できる
3. 誘われた人：リンク／QRを開く → ニックネームと生年月日を入れる（見せない場合はチェック）→「参加する」
4. 参加した瞬間に、その人と誘った人の相性が出る。誘った人の画面にも1行ずつ増える
5. 3人目が入ると「みんなの相性表」が見られる。人が増えると表もその場で増える（6人まで）
6. 相性表のいちばん下の「みんなをバースデー帳に保存」で保存 → 保存したあとに登録の案内

見本：`見本_最初の画面_アイコン入り.png`（右の形）、`見本_みんなの相性表_上から下まで.png`

## 2. 人数・部屋
| 人数 | 出るもの |
|---|---|
| 2人 | 今と同じ1対1の結果 |
| 3〜6人 | みんなの相性表（3人＝3組、4人＝6組、5人＝10組、6人＝15組） |
- 6人になったら、それ以上は参加できない
- LINEで送るリンクも、QRの4けたの番号も、**10分**で使えなくなる（参加の受付が終わる）
- 相性表は、参加した**全員**が見られる
- グループのデータ（ニックネーム・生年月日・タイプ・相性）は、作ってから**24時間**でサーバーから自動で消す。残したい人はバースデー帳に保存する
- LINEで送るのは、LINEの共有のURL（`https://line.me/R/share?text=` ＋文）で十分です（何人でも・グループでも選べる）。LINEの公式マークは形や色を変えて使えないので、ボタンの絵はオリジナルの吹き出し（下のアイコン表）

LINEで送る文の例：「みんなで相性しらべよ〜！あなたは何タイプ？生年月日を見せたくないときは、かくせるよ」＋リンク

## 3. 回数（1日5回まで）の数え方
- 誘った人：グループ1つで **1回**（6人でも1回）
- 誘われた人：**回数に数えない**。5回を使い切っていても参加できる
- 5回のあとに、自分で新しいグループを作るときは、ほかの診断と同じく登録が必要
- 登録している人（開運予報の会員）は、今と同じく回数制限なし

## 4. 生年月日の扱い
- 基本は、生年月日（**年も含む**）をグループの人に見せる
- 誕生日を入れるところの下に「□ 生年月日をみんなに見せない」（最初はチェックなし）
  - 上に鍵の絵と「生年月日は、このグループの人にだけ見えます」
  - チェックを入れると「生年月日はかくれます。みんなに見えるのは、名前とタイプと相性だけです」
  - 下に小さく「あとから、自分で見せる・かくすを切りかえられます」
- **見せない人の生年月日はサーバーに送らない**：スマホの中でタイプ（干支）に変えて、タイプだけ送る。相性の計算はタイプだけでできます
- 見せる人だけ、生年月日をサーバーに送る
- 相性表の中で名前を押すと、その人のタイプと生年月日（見せない人は「生年月日はひみつ」）
- 見本：`見本_生年月日をかくすチェック.png`

## 6. みんなの相性表の画面
タブは使わず、1つの画面に上から順に並べる。
1. 「みんなの相性表」「◯人・◯組」と表（6人までのマス目。自分どうしのマスは「－」）
2. マークの説明（4つ）と、その下に小さくサイトのアイコンと「1.66 奇跡の相性診断　166unmei.com」（スクショにサイト名が写るように）
3. ハートの組み合わせを一覧で（左に「あなた×りく」、右に短い名前）
4. 星の組み合わせ
5. 握手と双葉は最初は閉じる。「ほかの組み合わせ（◯組）を見る ▼」で開く（文字の色は少しおさえる）
6. 「行を押すと、続きが読めます」（小さく）
7. 「みんなをバースデー帳に保存」ボタン（ケーキの絵）と、その下に「保存すると、名前を押してくわしく見られる・1対1ですぐ占える・誕生日まであと何日」

押したとき
- 表のマスを押す：下にカード（二人の名前／マークと名前／短い名前（大きく）／もとの長い名前／とじる）
- 一覧の行を押す：その行の下に、もとの長い名前

**言葉の途中で改行しない（泣き別れ禁止）**
- 改行してよいのは「、」のあとだけ（「、」で区切ったかたまりごとに `white-space:nowrap` の inline-block にする）
- 短い名前・二人の名前は折り返さない
- 24個の長い名前は、カードで「好きだからこそ、ぶつかることもある二人」だけ2行（「好きだからこそ、」で分かれる）。ほかは1行に収まることを確かめずみ

見本：`見本_みんなの相性表_上から下まで.png`、`見本_押すと続きが読める.png`

## 7. バースデー帳
今の「電話帳」（「＋ この相手に名前をつけて保存」・localStorage の `enbiyori_contacts`）を、一覧で見られる「バースデー帳」にします。
- 入口：上のメニューなどに、ケーキの絵（`10_バースデー帳_ケーキ.png`）と「バースデー帳」
- 見出し「バースデー帳」、小さく「誕生日と相性のメモ」
- 誕生日が明日・今日の人がいると、いちばん上に「あしたは、ゆかさんの誕生日」
- 一覧（誕生日が近い順）：あなたとの相性のマーク／名前／「あと◯日」（明日は「あした」）／生年月日／タイプ名
- 生年月日をかくした人：「生年月日はひみつ」、一覧のいちばん下
- 名前を押す：生年月日・タイプ・あなたとの相性（マーク・短い名前・長い名前）と「この人と1対1で占う」（生年月日を入れた状態でいつもの診断へ）「名前を直す」「バースデー帳から消す」
- 「＋ 新しく書きこむ」（今の電話帳と同じ）
- 人の一覧の下に「保存した、みんなの相性表」（例：6人の相性表　11月17日）。押すと見返せる
- 保存先
  - 登録なし：そのスマホの中だけ（localStorage）。いちばん下に「今は、このスマホの中だけに保存されています。」と登録の案内
  - 登録あり：サーバー（開運予報の会員にひもづけ）。機種変更しても消えない。いちばん上に「✓ 登録しました。機種変更しても消えません」（登録した直後）
- **誕生日の前の日のお知らせ（毎朝のメールに1行）は、まだ作らないでください。** 日付の計算（日本時間・2月29日生まれなど）を十分に試してから、あとで足します。それまでは画面にもポリシーにも「お知らせします」と書かない

### 相性表から保存する流れ
1. 「みんなをバースデー帳に保存」を押す → 下から画面。参加者がチェック付きで並ぶ（最初は全員チェック）。かくした人は「生年月日はひみつ／名前とタイプだけ保存します」
2. 「◯人をバースデー帳に保存」→「◯人と、この相性表を保存しました」＋「バースデー帳を見る」＋登録の案内
3. 登録の案内のボタン「誕生日も相性も、ずっと残そう」を押す → 下から小さな登録の画面
   - 見出し「誕生日も相性も、ずっと残そう」（「、」のあとで改行）
   - ✓ 機種変更しても消えない／✓ みんなの相性表を、何度でも／✓ 毎朝の開運予報も届く
   - メールアドレス、「登録する」、小さく「料金はかかりません」、「あとで」

  - LINEの緑の大きなボタン「LINEでみんなを誘う」と、ピンクの大きなボタン「いま一緒にいる人と、その場でQR」（同じ大きさ。押すと登録の案内）

- 診断の途中（参加を待っている間・相性表を見ている間）は、ポップアップを出さない
- 誘われて参加した人には、ポップアップを出さない。結果の下に小さく「あなたも、だれかを誘ってみる？／みんなの相性表をつくる」と開運予報の案内だけ

## 11. 言葉の決まり（オーナーのルール）
- 「無料」は使わず「料金はかかりません」
- 結果の言葉は、低い組み合わせでも傷つかないように、やんわりした言い方にする（短い名前もこの考えで決めています）
- 「推し」とははっきり書かない（「だれとの相性も」）
