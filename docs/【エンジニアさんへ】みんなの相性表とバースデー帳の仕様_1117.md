## 1. 全体の流れ
1. 誘う人：トップで自分の生年月日を入れる → お相手の欄で「わからない」→「LINEで誘う」か「いま一緒にいる人と（QR）」
2. グループ（部屋）ができる。LINEのリンク、またはQR＋4けたの番号で参加できる
3. 誘われた人：リンク／QRを開く → ニックネームと生年月日を入れる（見せたくない人は「見せない」を選ぶ）→「参加する」
4. 参加した瞬間に、その人と誘った人の相性が出る。誘った人の画面は、開き直す（または「新しく入った人を見る」ボタンを押す）と、入った人が増える
5. 3人目が入ると「みんなの相性表」が見られる。人が増えた分は、開き直すと表に入る（6人まで）
6. 相性表のいちばん下の「みんなをバースデー帳に保存」で保存 → 保存したあとに登録の案内

見本：`見本_最初の画面_アイコン入り.png`（右の形）、`見本_みんなの相性表_上から下まで.png`

## 2. 人数・部屋
| 人数 | 出るもの |
|---|---|
| 2人 | 今と同じ1対1の結果 |
| 3〜6人 | みんなの相性表（3人＝3組、4人＝6組、5人＝10組、6人＝15組） |
- 6人になったら、それ以上は参加できない
- 参加の受付の時間は、誘い方で分ける（11月19日に変更・オーナー決定）
  - **LINEで送るリンク：24時間**（相性表を見られる時間とそろえる。授業中・仕事中・寝ているときなど、すぐ開けない人がいるため）
  - **QRと4けたの番号：10分**（その場にいる人だけが使う。番号は短いので、長くすると知らない人に当てられやすいため）
  - どちらも、6人になったらそこで締め切る
- 相性表は、参加した**全員**が見られる
- グループのデータ（ニックネーム・生年月日・タイプ・相性）は、作ってから**24時間**でサーバーから自動で消す。残したい人はバースデー帳に保存する
- LINEで送るのは、LINEの共有のURL（`https://line.me/R/share?text=` ＋文）で十分です（何人でも・グループでも選べる）。LINEの公式マークは形や色を変えて使えないので、ボタンの絵はオリジナルの吹き出し（下のアイコン表）

LINEで送る文（11月18日 オーナー決定）：「あなたは60タイプのうち、どのタイプでしょうか。生まれた日に宿るタイプから、みんなとの相性を読み解きます。受付は24時間までです。」＋リンク
- ていねいな言い方にする（タメ口にしない）。「生年月日を入れるだけ」の言い方は使わない

## 3. 回数（1日5回まで）の数え方
- 誘った人：グループ1つで **1回**（6人でも1回）
- 誘われた人：**回数に数えない**。5回を使い切っていても参加できる
- 5回のあとに、自分で新しいグループを作るときは、ほかの診断と同じく登録が必要
- 登録している人（開運予報の会員）は、今と同じく回数制限なし

## 4. 生年月日の扱い
- 基本は、生年月日（**年も含む**）をグループの人に見せる
- 誕生日を入れるところの下に、「グループの人に、生年月日を」と、2つのボタン「見せる」「見せない」（チェックボックスは使わない）
  - 最初は「見せる」が選ばれている。選んでいるほうを白く、ピンクの文字にする
  - その下の一文は、今の状態だけを書く（鍵の絵つき）
    - 「見せる」のとき：「このグループの人に、あなたの生年月日が見えます」
    - 「見せない」のとき：「生年月日は、だれにも見えません。見えるのは、名前とタイプと相性だけです」
  - 下に小さく「あとから、いつでも切りかえられます」
- **見せない人の生年月日はサーバーに送らない**：スマホの中でタイプ（干支）に変えて、タイプだけ送る。相性の計算はタイプだけでできます
- 見せる人だけ、生年月日をサーバーに送る
- 相性表の中で名前を押すと、その人のタイプと生年月日（見せない人は「生年月日はひみつ」）
- 見本：`見本_見せる見せないの切りかえ.png`

## 7. バースデー帳
今の「電話帳」（「＋ この相手に名前をつけて保存」・localStorage の `enbiyori_contacts`）を、一覧で見られる「バースデー帳」にします。
- 入口：上のメニューなどに、ケーキの絵（`10_バースデー帳_ケーキ.png`）と「バースデー帳」
- 見出し「バースデー帳」、小さく「誕生日と相性のメモ」
- 誕生日が明日・今日の人がいると、いちばん上に「あしたは、ゆかさんの誕生日」
- 一覧（誕生日が近い順）：あなたとの相性のマーク／名前／「あと◯日」（明日は「あした」）／生年月日／タイプ名
- 生年月日をかくした人：「生年月日はひみつ」、一覧のいちばん下
- 名前を押す：生年月日・タイプ・あなたとの相性（マーク・短い名前・長い名前）と「この人と1対1で占う」（生年月日を入れた状態でいつもの診断へ）「名前を直す」「バースデー帳から消す」
- 「＋ 新しく書きこむ」（今の電話帳と同じ）
- 人の一覧の下に「保存した、みんなの相性表」（例：6人の相性表　11月17日）。押すと見返せる
- 保存先
  - 登録なし：そのスマホの中だけ（localStorage）。いちばん下に登録の案内（下の「登録の案内の言葉」）
  - 登録あり：サーバー（開運予報の会員にひもづけ）。機種変更しても消えない。いちばん上に「✓ 登録しました。機種変更しても消えません」（登録した直後）
- **誕生日の前の日のお知らせ（毎朝のメールに1行）は、まだ作らないでください。** 日付の計算（日本時間・2月29日生まれなど）を十分に試してから、あとで足します。それまでは画面にもポリシーにも「お知らせします」と書かない

### 相性表から保存する流れ
1. 「みんなをバースデー帳に保存」を押す → 下から画面。参加者がチェック付きで並ぶ（最初は全員チェック）。かくした人は「生年月日はひみつ／名前とタイプだけ保存します」
2. 「◯人をバースデー帳に保存」→「◯人と、この相性表を、このスマホに保存しました」＋「バースデー帳を見る」＋登録の案内
   - **登録の案内の言葉**（11月19日に変更・オーナー決定。バースデー帳のいちばん下も同じ）：
     - 小さく（ふつうの色）「このスマホの中の保存です。機種変更などで消えてしまうこともあります。」
     - その下にローズの文字で「ご登録（料金はかかりません）で、消えずに残せます。」
     - その下にボタン「誕生日も相性も、ずっと残そう」
   - 「しばらく開かないと」のような、開かないと消すと聞こえる言い方は使わない（iPhoneのSafariは、しばらく開かないサイトの保存を消すことがあるが、「など」に入れて、くわしく書かない）
   - 登録しないで保存したものに、期限はない（24時間で消えるのは、サーバーのみんなの相性表だけ）
3. 登録の案内のボタン「誕生日も相性も、ずっと残そう」を押す → 下から小さな登録の画面
   - 見出し「誕生日も相性も、ずっと残そう」（「、」のあとで改行）
   - ✓ 機種変更しても消えない／✓ みんなの相性表を、何度でも／✓ 毎朝の開運予報も届く
   - **誘われて参加した人に出すときだけ**（11月19日に追加・オーナー決定）：初めてサイトに来た人が多いので、3つ目を「✓ あなたの毎朝の運勢も、メールで届く」にして、その下に小さく「生年月日から読み解いた『私だけの開運予報』が、毎朝6時に届きます（1.66と同じ運営です）」を足す。誘った人には、今のまま
   - メールアドレス、「登録する」、小さく「料金はかかりません」、「あとで」

### 「あなたはどのキャラ？」の枠（11月18日に追加・オーナー決定）
3つのカードを入れると、診断の入力までが長くなるため、今の図鑑の枠（`.hero-zukan`）を小さくして、余白も詰めます。**枠は消さないでください。**
- 置く場所：3つのカードのすぐ下
- 形：白い1行の枠（横いっぱい・カードと同じ幅）。左にキャラの顔3つ（少し重ねる）、まん中に「あなたは、どのキャラ？」と小さく「生まれた日の干支キャラ 全60種」、右に「図鑑 →」。押すと今と同じ `zukan.html`
  - 枠：白、`border:1.5px solid #ecc48f`、角丸16px、上下の内側9px
  - 顔：`img/mascot/thumb/` の絵を38px の丸で3つ（今の枠の左の3つ：乙卯・甲子・丙午）。2つ目からは左に10px重ねる
  - 文字：「あなたは、どのキャラ？」は明朝の太字15px、下の小さい文字は11px（`#8a7a68`）、「図鑑 →」は13px（`#c8662a`）。どれも途中で改行しない
- 今の大きな枠（キャラ5つ＋「干支キャラ図鑑を見る →」のボタン）は、この1行の枠に置きかえる
- **▼の矢印（`#heroDown`）はなくす。** あわせて、その上下の余白を詰める（`.hero-screen` の下の余白 28px → 6px、`#diag` の上の余白 6px → 0、1行の枠の下は14px）
- これで、カードを足しても、診断の入力までの長さは今より73pxふえるだけになります（▼を残したままだと＋172px）

### 無理な作りにしない（オーナーの指示：不具合が起きそうなことはしない）
- **人の並び・相性表は、開いた時点のものだけを出す。** その場で自動で増やす（リアルタイムの更新）はしない。新しく入った人は、開き直すか「新しく入った人を見る」ボタンで出す
- **残り時間（あと◯分）は出さない。** 「受付は、誘われてから24時間まで」（QR・番号は「10分まで」）と書くだけ（スマホの時計のずれで、表示がずれないように）
- 受付の締め切り（LINEは24時間・QRは10分）と、24時間の消去は、サーバーの時刻で判断する
