# 【エンジニアさんへ】開運カレンダーの ◎〇△ の決め方の直し（11月27日 オーナー決定・案B＋）

## なぜ直すのか
人によっては、合わない月に △ が月の3分の1以上（多いと13〜14日）になっていました。反対に、合う月は ◎ ばかりになります。
カレンダーはひと目で見るものなので、△ が多いだけで「今月はよくない」と感じてしまいます。
そこで、**どの月も同じ基準で比べて、△ は「本当に点数が低い日」だけにする**ことになりました。

## 原因
1. 年と月の補正（`ymAdjust`）を、その日の点数にだけ足していました。△ と ◎ の線（`gradeThresholds`：60日分の点数の下から15％・上から28％）には足していません。
   そのため、合わない月はひと月の全部の日の点数が下がって、線の下に落ちる日がまとめて増えていました。
2. △ の判定が `s <= th.tri` で、線と**同じ点数**の日も △ にしていました。点数は細かい数ではなく同じ点の日が多いので、ここでも △ が増えていました。


## 変わらないこと
- 日ごとの点数の出し方（その日の干支と本人の組み合わせ・喜神／忌神・冲）
- △ と ◎ の線の決め方（その人の60日分の点数の下から15％・上から28％）
- 天戦地冲（⚡）の日は必ず △、天地徳合（🌈）の日は 💮
- カレンダーのマスの印（🌈・💖・🌸・⚠️・💼・💰 など）の出し方と、見た目・絵文字・Googleカレンダーの色
- `ymAdjust()` の関数は消さないでください（ほかで使っているところがあれば、そのままにしてください）

## 変わること
- どの月も、△ は月に2〜7日（平均4〜5日）、◎ は10〜16日くらいにそろいます。今は △ が2〜14日、◎ が2〜20日と、月と人によって大きくばらついていました（200人×12か月で確かめました）。
- 合わない月は △ が減って ◎ が増えます。合う月は ◎ が少し減ることがあります（◎ が多すぎた月で、多くて6日）。
- △ が今より増える月は、200人×12か月（2,400か月分）で1つもありませんでした。
- ◎〇△ から決まるもの（メールの天気・指数、△ の日のデート服の見出し、今日のまとめの文など）も、新しい ◎〇△ に合わせて変わります。
- 💮（桃花×高い点の日）は、合わない月に少し増えることがあります。
