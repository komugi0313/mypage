# 【エンジニアさんへ】登録・ログイン・配信停止の画面の色の直し（11月18日）

開運予報の登録まわりの画面が、オレンジのグラデーションと青空の背景で見づらいため、色を落ち着かせます（オーナー決定）。
**変えるのは色だけです。** 文・並び・動き・入力の項目・ログインのしくみは変えません。

見本：`docs/見本_登録まわりの色_決定.png`（くらべた案：`docs/見本_登録まわり_今とAの間.png` の「C」と「D」）

## どの画面に、どちらを入れるか
| ページ | 入れるもの | 形 |
|---|---|---|
| `register.html`（登録・確認コード・登録完了） | 下の「C」 | 上の帯とボタンは残して、色をオレンジからローズに。背景の青空をやめて、うすいピーチ色 |
| `login.html`（ログイン・アドレスを直す） | 下の「C」 | 同じ |
| `unsubscribe.html`（配信停止・再開・停止できなかったとき） | 下の「D」 | 帯はつけない（止めた人に見せる画面なので、目立たせない）。見出しの文字をローズに |

## 入れ方
- それぞれのページの `</head>` のすぐ前に、`<style id="calm1118">…</style>` として入れてください（いちばん最後に読まれるように）。
- **ログインのページについて**：本番のログイン画面は、こちらで持っている古い形（確認コード）から、パスワード・Google・LINEの形に作りかえていただいていると思います。下のCSSは古い形のクラス名（`.bg` `h1` `.read` `.sub` `.card` `.submit` `.hdr` `.back` `.reg` `.foot` など）で書いています。本番のページでクラス名がちがうところは、同じ見た目になるように合わせてください（考え方：背景はうすいピーチ、上の見出しはローズのグラデーションの帯に白い文字、メインのボタンはローズのグラデーション、オレンジ色はローズ `#c24f6c` に置きかえ、青空の雲の飾りは消す）。Google・LINEのボタンの色は、それぞれの決まりの色のまま変えないでください。
- 見本の画面にある黄色い「開発モード」の枠は、確認用のファイルだけに出るものです（本番では出ません）。

## もうひとつ：トップ（index.html）のボタンのはみ出し（11月18日）
開運予報のトップの「開運カレンダー」の見本の下にある「👆 自分のカレンダーを作ってみる」のボタン（`.lpcal-cta`）が、白い枠（`.cal`、`overflow:hidden`）のいちばん下にぴったりくっついていて、スマホでボタンの下がはみ出して（切れて）見えます。ボタンの下にゆとりを作ります。
`index.html` の `</head>` の前に：
```css
<style id="lpcalFix1118">.lpcal-cta{margin:14px auto 22px!important;width:calc(100% - 32px)!important;box-sizing:border-box}</style>
```
見本：`docs/見本_開運予報トップのボタンのはみ出し.png`（左が今、右が直したあと）

## 確かめてほしいこと
- 青空の背景や雲が、どこにも残っていないこと（スクロールした下のほうも）
- オレンジの文字・枠が残っていないこと（エラーの赤い文字は、そのままでOK）
- ログインの下の小さな文字（ログインでお困りのときは…）が、うすい背景の上で読めること
- スマホの幅（360px・390px）で、文字が言葉の途中で改行されていないこと
