## 2. 直していただきたいこと

### 2-1. 運営者情報のページから「所在地」を消す（サイト）

- `https://unkiyoho.jp/tokushoho.html` に「所在地」（住所）が表示されています。
- 運気予報は無料のサービスなので、**住所は載せない方針**です（オーナー決定）。**「所在地」の行を削除してください。**

- ※ 有料の Pocket鑑定は、Pocket鑑定のサイト側の表記に従います（運気予報のサイトには載せません）。

### 2-2. メールのシェアURLに、会員ごとの紹介コードを渡す（送信バッチ）

- 届いたメールのシェアのURLが `https://unkiyoho.jp/?ref=mail` になっていました。
- `mail` は、紹介コードが渡されなかったときの仮の値です。このままだと、シェアからの登録が「誰の紹介か」を数えられません。
- `renderDailyMail()` に、会員ごとの紹介コードを渡してください（仕様書 §3・§5-3）。

```js
const mail = renderDailyMail(r, { /* …今と同じ… */, refCode: member.ref_code });
```

### 2-3. メールの組み立てファイルを新しくする（`mail-template/`）

`mail-template/render-daily-mail.js` を、このZIPのものに差し替えてください（差分：`差分/render-daily-mail.js_0930版からの差分.patch`）。変わるのは次の3点だけです。**運勢の計算（エンジン）は1文字も変えていません。**

**(1)「仕事・対人（→ 仕事も恋も、バランスよく）」の人にも「💗 恋愛・ご縁」を出す**
- これまで、今の状況が「仕事・対人（`rel: 'work'`）」の会員には、恋愛・ご縁の欄を出していませんでした。
- 恋愛が主役のメールなので、**全員に出す**ことにしました（オーナー決定）。
- 「仕事・対人」の人の見出しは、相手の有無を決めつけない「今日のご縁」。中身は 今日のご縁 → 今日の恋愛運 → 今日の恋の一手 → 縁が活きる場所。
- 文章はエンジンがもともと「仕事・対人」の人向けに作っていたものを表示するだけです。

**(2) メールに「Special Reading」の細いバナー3枚を入れる**
- 季節のたよりの下、シェアのボタンの上に、LPの「Special Reading」と同じ色・書体の**細いバナー画像**を3枚並べます。
  - `mail-bg/sr-166.jpg`：1.66 奇跡の相性診断 → `https://166unmei.com/`（`aishouUrl`）
  - `mail-bg/sr-nicocale.jpg`：ニコカレ（近日公開）→ 運気予報トップの紹介 `https://unkiyoho.jp/#sisters`
  - `mail-bg/sr-pocket.jpg`：Pocket鑑定（近日公開）→ 同上
- これまでのピンクの「1.66 相性診断をやってみる」カードは、このバナーに置き換えました。シェアのボタン（LINE・X・PC用URL）はそのまま残っています。
- **3枚の画像を `https://unkiyoho.jp/mail-bg/` にアップロードしてください**（各12〜15KB）。LPのメール見本（`mail-preview.html`）でも使うので、サイトの `mail-bg/` にも同じものを置きます。
- 画像なので、グラデーションもダークモードで崩れません（文字の箱にグラデーションを使わない、というルールは今までどおりです）。
- ニコカレ・Pocket鑑定を公開するときは、オーナーから新しい画像（「近日公開」→ボタン）とリンク先をお渡しします。

**(3) 7月のテーマ名を「七夕」に**
