# 【エンジニアさんへ】Googleカレンダー連携の決まり（10月23日版）

今のGoogleカレンダー連携を、次の形に作り直してください。

今の動きとのちがいは、次の3つです。

| | 今 | これから |
|---|---|---|
| タイトル | どの日も「開運予報」 | その日の特徴（例「💰金運」「🌸恋愛運」） |
| 色 | 全部ミカン色 | 運の種類で色分け |
| 期間 | 2か月 | 1年先まで |

---

## 1. 予定の中身は `gcal-events.js` から出す（いちばん大事）

- 開運予報のZIP（`開運予報_本番用_1023_7.zip`）に、新しいファイル **`gcal-events.js`** を1つ足しました。
- この部品が、1人1日分の予定（タイトル・色・中身・ID・日付）をそのまま作ります。
- 中身は、毎朝のメールと同じ `daily-engine.js` の結果から作ります。マイページの開運カレンダーと同じ印・同じランクになることを確かめ済みです（40人×400日＝1万6千日分、食いちがい0件）。
- **運勢の計算を、エンジニアさん側で作り直さないでください。** 作り直すと、メール・マイページ・Googleカレンダーで印や点数が食いちがいます。

```js
const G = require('./gcal-events.js');            // daily-engine.js・bazi.js・engine.js と同じフォルダに置く
const events = G.buildEvents({
  birth:   { y: 1990, m: 2, d: 26 },               // 登録の生年月日
  profile: { rel: 'crush', sex: 'f', hour: null, minute: null, timeUnknown: true },  // 毎朝のメールに渡しているのと同じ登録情報
  from:    { y: 2026, m: 10, d: 23 },              // 日本時間の「今日」
  days:    365,                                    // 1年先まで
  userKey: '会員ごとに変わらない番号',               // 予定のIDを作るため（メールアドレスそのものは入れない）
  gen:     1                                       // 「登録する」を押した回数（やめて再登録したら +1）
});
// Googleに送るとき： G.toGoogle(events[i])（確認用の _check を外したもの）
// → そのまま Calendar API の events.insert / events.update に渡せます。
```

## 2. 予定の形（部品が作ります。参考）

| 項目 | 中身 |
|---|---|
| 日付 | **終日の予定**。`start.date` に日本時間の日付（YYYY-MM-DD）、`end.date` は次の日。時刻つき（dateTime）にしないこと。時刻つきにすると、日本以外の設定の人などで1日ずれます。 |
| タイトル | マイページのカレンダーのマスと同じ印の、短い名前。例：「🌈大吉日」「💰金運 🍀」「⚠️注意 💼」。印がない日は「◎好調」「〇ふつう」「△ひかえめ」。 |
| 色（colorId） | 🌈大吉日＝3（ブドウ）、🌸🌷💖 恋＝4（フラミンゴ）、💰金運＝5（バナナ）、💼仕事＝9（ブルーベリー）、🌐🍀 対人・貴人＝7（ピーコック）、📚学び＝2（セージ）、🐴お出かけ＝10（バジル）、印なし・注意だけ＝8（グラファイト） |
| 中身（description） | その日のランクと点数、天気の一言、印の正式な名前、注意の日の説明、マイページへのリンク（`mypage.html#d-2026-12-05` の形。タップすると、その日のくわしい鑑定が開いた状態でマイページが出る。ログインをはさんでも有効） |
| 通知 | しない（`reminders: {useDefault:false, overrides:[]}`） |
| 予定あり／なし | 予定ありにしない（`transparency: 'transparent'`） |
| ID | 「この人・この日・何回目の登録か」で決まる番号。同じ予定は同じIDになるので、入れ直しても二重に入りません。 |

## 3. 期間と入れ方（1年先まで）

1. 「登録する」を押したら、**今月と来月の分をすぐ**入れる（押した人にすぐ見えるように）。
2. **残りの分は、裏で少しずつ**入れて、1年先（365日分）までそろえる。
3. その後は毎日（または毎月1日）、**いつも1年先まで入っている状態**になるよう、足りない日を足す。
   - 先生や会員さんが手で何かをする必要はありません。サーバーが自動で行います。
4. 一度にたくさん送らないこと。Googleの上限に当たると、途中で止まったり、一部の日が入らなかったりします。
   - まとめて送る（バッチ）
   - 少し間をあける
   - 上限のエラー（429、または 403 の rateLimitExceeded）が返ってきたら、時間をおいてやり直す

## 4. 入れ直しが必要なとき

- マイページで「今の状況（片思い・恋人・既婚など）」「性別」「生まれた時間」を変えたとき → 今日以降の予定を `events.update` で入れ直す（例：既婚にすると「🌷モテ運」が「🌷愛され運」になる）。
- 運勢の文や印の名前を直したとき（`daily-engine.js` などを差しかえたとき） → 全員の、今日以降の予定を裏で入れ直す。
- 同じIDの予定がすでにある（409 が返る）ときは、`insert` ではなく `update` にする。

## 5. 守ること（プライバシーポリシー・利用規約に書いた約束）

- 運勢は、**運勢専用のカレンダー（名前：私だけの開運予報）**を1つ作って、そこに入れる。会員さんのほかの予定は読まない・さわらない。
- 「登録をやめる」を押したら、①入れた予定をすべて消す（専用カレンダーごと消してよい）、②連携の情報（トークン）を消す。
- Googleから受け取った情報は、同期のためだけに使う。

## 6. 公開前の確認

1. 「登録する」を押すと、すぐ今月と来月の分が入る。しばらくすると、1年先まで入っている。
2. 月の表示で、タイトルが「💰金運」「🌸恋愛運」などになっている（「開運予報」ではない）。色が運の種類で分かれている。
3. ある日の予定の印が、マイページの開運カレンダーのその日のマスと同じ。
4. 予定は終日で、日付がマイページと1日もずれていない（年末年始も見る）。
5. マイページで今の状況を「結婚している」に変えると、🌷の予定が「愛され運」に変わる。
6. 「登録をやめる」を押すと、入れた予定がすべて消える。もう一度登録しても、二重に入らない。
7. 予定のリンクをタップすると、マイページで「その日」のくわしい鑑定が開く（ログインしていないときは、ログインのあとに開く）。
