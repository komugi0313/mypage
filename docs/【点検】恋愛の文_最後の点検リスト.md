# 恋愛の文　最後の点検リスト（11月14日）

60タイプすべての文を、プログラムでまとめて点検しました。
**直す前に、かならず直し案をお見せします。**

## 問題がなかったこと
- 60タイプすべて、文字数は決まった範囲に入っています（①36〜50、②108〜122、③143〜157）
- 「無料」「最強」「恋が動く日」「おちゃめ」は使っていません
- 甲子以外で「まっすぐ」は使っていません
- 干支の名前は、文の中に出てきません
- 「浮気」「火遊び」「不倫」「離婚」「見限る」は使っていません

## 見直す候補

### 1. ③に脈ありサインがない（12タイプ）
甲子・乙丑・丙寅・己巳・庚午・辛未・壬申・甲戌・丙子・庚辰・壬午・甲申
- 6つの形（〜のひとつ／〜と受けとってよさそう／〜のは、この人なりの〜／〜ときは、〜とき／〜なら、期待してよいでしょう／〜からこそ）を決める前に作った文です。
- 「〜を伝えること」「〜を認めること」のような、すすめる言い方が多くなっています。
- 己巳の「自信を持って。」、甲申の「話してみる。」も、すすめる言い方です。

### 2. ①に「〜さん」がある（6タイプ）
- 丙寅：寂しがりやさん
- 丁卯：もじもじ屋さん
- 戊辰：強がりさん
- 辛未：繊細さん
- 壬申：照れ屋さん
- 己丑：がまん屋さん

### 3. ①にギャップがない（4タイプ）
- 甲戌：一度好きになったら、何があっても味方でいる一途な人。約束は必ず守る、頼れるヒーロー。
- 己卯：好きな人を喜ばせるのが、何よりうれしい人。記念日もサプライズも、心をこめて準備するロマンチスト。
- 癸亥：好きな人の小さな変化に、すぐ気づく人。相手の気持ちを、自分のことのように抱えこむ愛情家。
- 己丑：つい「大丈夫」と言ってしまう、がまん屋さん。一度好きになったら、とことん支える人。

### 4. ①と③で同じ言い回しがある（5タイプ）
- 乙亥：「言葉より、そばにいる」
- 己亥：「温かいのに、」
- 庚辰：「を秘めた人」
- 乙酉：「好きな人の前」
- 癸酉：「だからこそ」

### 5. 「かもしれません」が残っている（2か所）
- 庚午③：戸惑うこともあるかもしれません
- 庚辰②：言いたいことを飲みこむ夜もあるかもしれません

### 6. ほかのタイプと、終わりの文が同じ
- ②：丙寅・乙未「…と伝えてみて。」／庚戌・辛亥「…大切にしてみて。」（どちらも、すすめる言い方です）
- ③：己卯・辛巳「…と変わっていきます。」／庚辰・辛卯「…ない存在になります。」／壬午・丙申「…たいと思える人です。」／癸未・己酉「…のになっていきます。」／丙午・癸丑「…を注ぎ続ける人です。」

### 7. 何度も出てくる言葉
- 「距離を縮め」12タイプ
- 「受けとめ」12タイプ
- 「心を許し」8タイプ

### 8. 気になる言葉（直さなくてもよさそう）
- 辛亥②「束縛は苦手」：相手をしばる話ではなく、この人が自由でいたいという意味です。
