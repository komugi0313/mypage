## 1. 天戦地冲とは

2つの干支（柱）が、**天干どうしでやっつけ合い、同時に地支どうしでもぶつかる**関係です。干と支の両方が正面からぶつかるため、干支関係の中で最も刺激の強いものとして扱います。

当ツールでは「凶」と決めつけず、**破壊と再生がセット**（壊れた先に新しいステージがある）として、飛躍のきっかけとして前向きに読みます。

## 2. 判定条件（3つすべてを満たすと成立）

| | 条件 | 内容 |
|---|---|---|
| ① | 天干の陰陽が同じ | 陽干（甲丙戊庚壬）どうし、または陰干（乙丁己辛癸）どうし |
| ② | 天干が相剋 | 木剋土・土剋水・水剋火・火剋金・金剋木 のどれか |
| ③ | 地支が冲 | 子午・丑未・寅申・卯酉・辰戌・巳亥 のどれか |

**土（戊・己）も含めます。** 天干七冲（甲庚・乙辛・丙壬・丁癸）の4組だけに絞る流派もありますが、当ツールは「天干が相剋関係で、地支が冲」という一般的な定義を採用しています（世間一般の鑑定結果と一致させるため）。なので次の組も成立します。

- 木剋土：甲×戊、乙×己
- 土剋水：戊×壬、己×癸

成立する組み合わせは **60組**（順序を区別すると120通り）です。全一覧は付録Aにあります。

### 2-1. 天干ごとの相手表

| 天干 | 自分が剋す相手 | 自分を剋す相手 |
|---|---|---|
| 甲（木・陽） | 戊 | 庚 |
| 乙（木・陰） | 己 | 辛 |
| 丙（火・陽） | 庚 | 壬 |
| 丁（火・陰） | 辛 | 癸 |
| 戊（土・陽） | 壬 | 甲 |
| 己（土・陰） | 癸 | 乙 |
| 庚（金・陽） | 甲 | 丙 |
| 辛（金・陰） | 乙 | 丁 |
| 壬（水・陽） | 丙 | 戊 |
| 癸（水・陰） | 丁 | 己 |

コードでは各天干を `[自分が剋す相手, 自分を剋す相手]` の配列で持ちます。

```js
const TENSEN_MAP={甲:['戊','庚'],乙:['己','辛'],丙:['庚','壬'],丁:['辛','癸'],戊:['壬','甲'],
                  己:['癸','乙'],庚:['甲','丙'],辛:['乙','丁'],壬:['丙','戊'],癸:['丁','己']};
```

> 注意：以前、戊と己の並びが逆（戊:['甲','壬']、己:['乙','癸']）になっていて、戊・己が絡むときだけ向きが真逆に出る不具合がありました。上の並びが正しいものです。

### 2-2. 判定式

```js
const BR='子丑寅卯辰巳午未申酉戌亥';
function isTensenChichu(gzA,gzB){                       // 干支は「甲子」のような2文字
  if(!gzA||!gzB||gzA.length<2||gzB.length<2) return false;
  return (TENSEN_MAP[gzA[0]]||[]).indexOf(gzB[0])>=0     // ①②：同じ陰陽で相剋
      && (BR.indexOf(gzA[1])+6)%12===BR.indexOf(gzB[1]); // ③：地支が冲（6つ離れている）
}
// gzA の天干が gzB の天干を剋すか（成立している組に対して使う）
function aControlsB(gzA,gzB){ return (TENSEN_MAP[gzA[0]]||[])[0]===gzB[0]; }
```

## 3. 向き（剋す／剋される）— 必ず区別する

天戦地冲は「どちらがどちらを剋しているか」で、起きることが真逆になります。**誰と誰の間で、どちら向きに剋が働いているか**を、判定でも文章でも必ず分けて出します。

| | 自分が剋す側 | 自分が剋される側 |
|---|---|---|
| 意味 | 発散・外へ圧力をかける・主導 | 試練・内省の葛藤・外から圧力を受ける |
| 出やすいこと | 自分から動いて現状を変えられる。反面、摩擦・衝突・独断・ねじ伏せに注意 | 内面で葛藤しやすい。受けて立てば逆転・急成長のきっかけになる（剋される側が結果的に強い影響力を持つこともある） |

「自分」は**日柱（日干）**です。

## 4. 判定する場面

### 4-1. 命式内（生まれ持った天戦地冲）

命式の柱どうしを総当たりで調べます。**2組以上あれば全部出します。**

- 対象の柱：時刻が分かる場合は年柱・月柱・日柱・時柱の4柱。**時刻が分からない場合は、いつでも年月日の3柱で鑑定します**（時柱は使わない）。
- 組ごとに「剋す側の柱 → 剋される側の柱」を決め、日柱が絡むかで3通りに読み分けます。

| 型 | 条件 | 読み方 |
|---|---|---|
| 外から自分へ（試練） | 他の柱 → 日柱 | その柱の領域から自分へ強い圧力・試練。内面の葛藤になりやすいが、受けて立てば逆転・急成長の起爆剤 |
| 自分から外へ（主導） | 日柱 → 他の柱 | 自分からその柱の領域へ強く働きかける。現状を変える推進力だが、ねじ伏せ・衝突に注意 |
| 柱どうしの綱引き | 日柱が絡まない | 2つの領域の間で激しい綱引き。内側に相反する力が同居 |

柱の領域（命式内で使う言葉）：

| 柱 | プロ向け | やさしい版 |
|---|---|---|
| 年柱 | 目上・親・社会／ルーツ | 目上・親・ルーツ |
| 月柱 | 仕事・家庭・社会的立場 | 仕事・家庭・社会での立場 |
| 日柱 | 自分自身・配偶者・内面 | 自分自身・パートナー |
| 時柱 | 子ども・将来・晩年・本音 | 子ども・将来・本音 |


> 大運の第一運（0歳〜立運＝月柱）は、命式内の「月柱×日柱」の判定に含まれます。

### 4-2. 運気（巡ってくる天戦地冲）

**日柱の干支**と、巡ってくる運の干支を比べます。

| 運 | 調べる範囲 | 表示例 |
|---|---|---|
| 大運 | 立運後のすべての大運 | 庚午（40〜50歳） |
| 年運 | 今年の前年〜20年後 | 2027年（45歳） |
| 月運 | 今月から12ヶ月（各月20日の月干支で判定） | 2026年11月ごろ（庚午） |

向きは「日干が運の干を剋す＝自分が剋す側」「運の干が日干を剋す＝自分が剋される側」です。大運・年運・月運をまとめて、向き別に2つの欄に分けて出します。影響の大きさは 大運＞年運＞月運 です。

> 現在、月運まで判定しているのはPROのみです（ビギナーは月運のデータを持っていないため大運・年運のみ）。

### 4-3. 相性（2人の命式クロス）

**本人の4柱 × 相手の4柱（最大16組）** を総当たりで調べ、成立したものを全部出します。時刻不明の人の時柱は除外します。

- **日柱どうし**が成立していれば「2人の核」として見出しにします（最重要）。
- それ以外の組は「ぶつかり合う領域」として、向き付きで並べます。例：本人の日柱×相手の年柱＝本人自身と、相手の親・家柄がぶつかる。
- 向きは「本人側が主導・発散 → 相手側が受けとめる」または「相手側が主導・発散 → 本人側が受けとめる」で表します。

柱の領域（相性で使う言葉）：

| 柱 | 意味 |
|---|---|
| 年柱 | 親・目上・家柄・育った環境 |
| 月柱 | 仕事・社会的立場・暮らしの基盤 |
| 日柱 | 本人自身・配偶者としての距離感 |
| 時柱 | 子ども・将来・晩年・本音の部分 |

### 4-4. 鑑定書

命式表の下の「この命式の特徴」に、命式内の天戦地冲を1組1行で出します。

```
・天戦地冲（年柱→日柱 己巳×癸亥・外から試練/内省）があります。
・天戦地冲（日柱→時柱 癸亥×丁巳・自分が主導/発散）があります。
・天戦地冲（年柱→時柱 己巳×癸亥）があります。        ← 日柱が絡まない組は向きの矢印のみ
```

## 5. 表示のルール

- 鑑定文にアスタリスク（`*`）を出さない。強調は太字タグで。
- サイト内で「AI」という語を使わない（「詳細鑑定」と言い換える）。
- 読みがなは「天戦地冲（てんせんちちゅう）」。

### 6-3. 相性

**日柱どうしが成立したとき（見出し）**
> ⚡ 天戦地冲（てんせんちちゅう）の縁 ＝ 日柱どうし {本人の日柱}×{相手の日柱}
> 2人の核（本人自身どうし）の日柱が、天干は相剋（考え方が真逆）・地支は冲（行動や環境が激しくぶつかる）でそろう、めったにない強烈な縁です。真逆だからこそ「自分にないもの」を感じて強く惹かれ合い、“魂の引き合い”に。相反するエネルギーが葛藤を生む一方で、お互いを大きく成長させる好機にもなります。

向きの一文：
- 本人が剋す側：▶ 向き：本人 → お相手（本人が主導・発散する側／お相手が受けとめる側）。本人がリードや刺激を与えやすく、お相手がそれを強く受け止める関係。
- 相手が剋す側：▶ 向き：お相手 → 本人（お相手が主導・発散する側／本人が受けとめる側）。お相手からの刺激・働きかけが強く、本人がそれを受け止める関係。

**日柱どうしは成立せず、他の柱だけのとき（見出し）**
> ⚡ 天戦地冲（てんせんちちゅう）のぶつかり
> 2人の命式の一部の柱に、天干は相剋・地支は冲でそろう強い刺激の縁があります（下記）。真逆だからこそ惹かれ合い、ぶつかりながら成長できる関係です。

**他の柱の組（ぶつかり合う領域）**
- ▶ {干支}×{干支}：本人の{柱}（{領域}）が主導 → お相手の{柱}（{領域}）が受けとめる
- ▶ {干支}×{干支}：お相手の{柱}（{領域}）が主導 → 本人の{柱}（{領域}）が受けとめる

**締め（共通）**
> 付き合い方のコツ：ベッタリ依存せず程よい距離感と、お互いのプライベート・違いの尊重を。ぶつかり合いを否定せず「修行・成長の機会」と捉えると、関係が安定します。「壊れた先に新しいステージがある」縁です。

## 7. 参照実装（JavaScript）

`docs/tensen-chichu/tensen-chichu.js` に、どの商品にも貼れる形で入っています（外部依存なし・古いブラウザでも動く書き方）。

| 関数 | 入力 | 出力 |
|---|---|---|
| `isTensen(gzA, gzB)` | 干支2つ | 成立するか |
| `aControlsB(gzA, gzB)` | 干支2つ | gzA の天干が gzB を剋すか |
| `natal([年,月,日,時])` | 命式の干支（時刻不明なら時柱は `''`） | `{from, to, fromGz, toGz, type}` の配列。type＝`pressured`/`attack`/`between` |
| `timing(日柱, runs)` | 日柱の干支と、`{kind, label, ganzhi}` の配列 | 該当した運に `dir`（`attack`/`pressured`）を付けた配列 |
| `compat(本人4柱, 相手4柱)` | 2人の干支（時刻不明なら時柱 `''`） | `{aPillar, bPillar, ga, gb, aControls, isDay}` の配列 |

命式の計算（干支を出す処理）は各商品の既存エンジンを使い、そこには手を入れません。このファイルは干支の文字列だけを受け取ります。
