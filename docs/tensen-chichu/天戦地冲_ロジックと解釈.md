## 1. 天戦地冲とは

2つの干支のあいだで、**天干どうしが剋し合い、同時に地支どうしも冲でぶつかる**組み合わせです。上（天干）と下（地支）が一度にぶつかるため、干支どうしの関係の中でもとくに衝撃が大きく、**基本的には凶**として扱います。

- 強く出る順：**大運＞年運＞命式内**（月運は短い期間の目安）。
- 良い面（役目を終えた関係や環境に区切りをつけ、次の段階へ移るきっかけ）は、**最後に短く添えるだけ**にします。凶を薄めて書かない。

## 2. 判定条件（3つすべてを満たすと成立）

| | 条件 | 内容 |
|---|---|---|
| ① | 天干の陰陽が同じ | 陽干（甲丙戊庚壬）どうし、または陰干（乙丁己辛癸）どうし |
| ② | 天干が相剋 | 木剋土・土剋水・水剋火・火剋金・金剋木 のどれか |
| ③ | 地支が冲 | 子午・丑未・寅申・卯酉・辰戌・巳亥 のどれか |

**土（戊・己）も含めます。** 天干七冲（甲庚・乙辛・丙壬・丁癸）の4組だけに絞る流派もありますが、当ツールは「天干が相剋関係で、地支が冲」という一般的な定義を採用しています（一般的な鑑定結果と一致させるため）。なので次の組も成立します。

- 木剋土：甲×戊、乙×己
- 土剋水：戊×壬、己×癸

成立する組み合わせは **60組**（順序を区別すると120通り）です。全一覧は付録Aにあります。

### 2-1. 天干ごとの相手表

| 天干 | 自分が剋す相手 | 自分を剋す相手 |
|---|---|---|
| 甲（木・陽） | 戊 | 庚 |
| 乙（木・陰） | 己 | 辛 |
| 丙（火・陽） | 庚 | 壬 |
| 丁（火・陰） | 辛 | 癸 |
| 戊（土・陽） | 壬 | 甲 |
| 己（土・陰） | 癸 | 乙 |
| 庚（金・陽） | 甲 | 丙 |
| 辛（金・陰） | 乙 | 丁 |
| 壬（水・陽） | 丙 | 戊 |
| 癸（水・陰） | 丁 | 己 |

コードでは各天干を `[自分が剋す相手, 自分を剋す相手]` の配列で持ちます。

```js
const TENSEN_MAP={甲:['戊','庚'],乙:['己','辛'],丙:['庚','壬'],丁:['辛','癸'],戊:['壬','甲'],
                  己:['癸','乙'],庚:['甲','丙'],辛:['乙','丁'],壬:['丙','戊'],癸:['丁','己']};
```

> 注意：以前、戊と己の並びが逆（戊:['甲','壬']、己:['乙','癸']）になっていて、戊・己が絡むときだけ向きが真逆に出る不具合がありました。上の並びが正しいものです。

### 2-2. 判定式

```js
const BR='子丑寅卯辰巳午未申酉戌亥';
function isTensenChichu(gzA,gzB){                       // 干支は「甲子」のような2文字
  if(!gzA||!gzB||gzA.length<2||gzB.length<2) return false;
  return (TENSEN_MAP[gzA[0]]||[]).indexOf(gzB[0])>=0     // ①②：同じ陰陽で相剋
      && (BR.indexOf(gzA[1])+6)%12===BR.indexOf(gzB[1]); // ③：地支が冲（6つ離れている）
}
// gzA の天干が gzB の天干を剋すか（成立している組に対して使う）
function aControlsB(gzA,gzB){ return (TENSEN_MAP[gzA[0]]||[])[0]===gzB[0]; }
```

## 3. 向き（剋す／剋される）— 必ず区別する

「どちらがどちらを剋しているか」で、出来事の起こり方が変わります。判定でも文章でも必ず分けます。

| | 剋される側（外から壊される） | 剋す側（自分から壊す） |
|---|---|---|
| 条件 | 相手（巡る運・ほかの柱）の天干が、自分の天干を剋す | 自分の天干が、相手の天干を剋す |
| 起こり方 | 本人の望みとは別のところで、周囲や環境の側から圧力・試練が持ち込まれる | 本人の言動がきっかけで、今の関係や状態を自ら崩してしまう。強引さ・独断に注意 |

「自分」は、運気では日柱（または月柱）、命式内では日柱です。

## 4. 判定する場面

### 4-1. 運気 × 日柱（本人・私生活）

日柱の干支と、巡る運（大運・年運・月運）の干支を比べます。

- 意味：暮らしの土台が揺らぎやすい時期。夫婦・パートナーや家族との関係に区切りがつく、親しい人と離れる、住まいが変わるなど、望む・望まないにかかわらず身の回りが入れ替わる出来事が起こりやすい。

### 4-2. 運気 × 月柱（仕事・社会での立場）

月柱の干支と、巡る運の干支を比べます。

- 意味：仕事の状況が大きく動きやすい時期。異動や配置換え、勤め先の業績悪化や組織の再編、取引の打ち切り、トラブルでの信用低下などに注意。退職・転職・独立の決断も重なりやすく、立場を落とすか大きく伸びるかの境目。

運気の調べる範囲（4-1・4-2 共通）：

| 運 | 範囲 | 表示例 |
|---|---|---|
| 大運 | 立運後のすべての大運 | 庚午（40〜50歳） |
| 年運 | 今年の前年〜20年後 | 2027年（45歳） |
| 月運 | 今月から12ヶ月（各月20日の月干支で判定） | 2026年11月ごろ（庚午） |

> 月運まで調べているのはPROのみ（ビギナーは月運データを持たないため大運・年運）。大運の第一運（0歳〜立運＝月柱）は、命式内の判定に含まれます。

運気が巡ったときは、心と体への負担（疲れやストレスの蓄積、気分の落ち込み、思いがけないケガや体調の崩れ）と、それまでの考え方が通用しなくなる動揺にも触れます。

**備え（必ず添える）**
1. 大きな投資や事業の拡大、一か八かの勝負はこの時期を外し、今あるものを守る。
2. 起きた変化を無理に元へ戻そうとしない（しがみつくほど傷が深くなる）。
3. 休養と体調管理を予定に組み込み、無理を重ねない。

### 4-3. 命式内（生まれ持った天戦地冲）

命式の柱どうしを総当たりで調べ、**2組以上あれば全部出します。**

- 対象の柱：時刻が分かる場合は年・月・日・時の4柱。**時刻が分からない場合は、いつでも年月日の3柱**（時柱は使わない）。
- 意味：相反する気持ちを同時に抱えやすく、心の中で折り合いがつきにくい。人生の起伏や試練も多くなりがち（巡ってくる運のときより影響は穏やか）。その反面、エネルギーが強く個性がはっきりしているため、自分のやり方を貫ける分野（表現・競技・独立した仕事など）では大きな力を出すことがある。

組ごとに「剋す側の柱 → 剋される側の柱」を決め、日柱が絡むかで読み分けます。

| 型 | 条件 | 読み方 |
|---|---|---|
| 外から自分が剋される | 他の柱 → 日柱 | その柱の領域から強い圧力や試練を受けやすく、内面の葛藤や消耗につながりやすい |
| 自分が外を剋す | 日柱 → 他の柱 | その柱の領域と正面からぶつかり、関係を壊しやすい。強引さ・独断に注意 |
| 柱どうしの衝突 | 日柱が絡まない | 2つの領域が両立しにくく、どちらかが崩れやすい |

柱の領域：

| 柱 | プロ向け | やさしい版 |
|---|---|---|
| 年柱 | 目上・親・社会／ルーツ | 目上・親・ルーツ |
| 月柱 | 仕事・家庭・社会的立場 | 仕事・家庭・社会での立場 |
| 日柱 | 自分自身・配偶者・内面 | 自分自身・パートナー |
| 時柱 | 子ども・将来・晩年・本音 | 子ども・将来・本音 |

### 4-4. 相性（2人の命式クロス）

**本人の4柱 × 相手の4柱（最大16組）** を総当たりで調べ、成立したものを全部出します。時刻不明の人の時柱は除外します。

- **日柱どうし**＝最重要（2人の核）。見出しにする。
- **日柱×月柱**（どちら向きでも）＝重要。【重要】と付ける。
- それ以外は「ぶつかり合う領域」として向き付きで並べる。
- 向き：剋す側＝相手を押さえつけ傷つけやすい側／剋される側＝圧力を受け気疲れしやすい側。

相性で使う柱の領域：年柱＝親・目上・家柄・育った環境／月柱＝仕事・社会的立場・暮らしの基盤／日柱＝本人自身・配偶者としての距離感／時柱＝子ども・将来・晩年・本音の部分。

### 4-5. 鑑定書

命式表の下の「この命式の特徴」に、命式内の天戦地冲を1組1行で出します。

```
・天戦地冲（年柱→日柱 己巳×癸亥・外から剋される（試練））があります。
・天戦地冲（日柱→時柱 癸亥×丁巳・自分から剋す（衝突））があります。
・天戦地冲（年柱→時柱 己巳×癸亥）があります。        ← 日柱が絡まない組は向きの矢印のみ
```

## 5. 表示のルール

- 該当すれば必ず出す。画面の確定カード＋詳細鑑定の材料＋端末内鑑定（オフライン）のすべてに入れる。複数あれば全部出す。
- 基本は凶として書く。起こりやすい出来事を具体的に書き、断定はしない（「起こりやすい」）。備えを必ず添え、良い面は最後に短く。
- 鑑定文にアスタリスク（`*`）を出さない。サイト内で「AI」という語を使わない（「詳細鑑定」と言い換える）。
- 読みがなは「天戦地冲（てんせんちちゅう）」。

## 6. 説明文（当ツールの文言）

`{ }` は判定結果で置き換えます。プロ向け（PRO）の文言です。やさしい版（ビギナー）は同じ内容を、大運＝「10年運」、年運＝「その年」と言い換え、文を短くしたものを使っています。

**導入**
> 天干どうしが同じ陰陽で剋し合い、地支どうしも真向かいで冲する組み合わせです。上（天干）と下（地支）が同時にぶつかるため、干支の関係の中でもっとも衝撃が大きく、基本的には凶として注意します。強く出る順は 大運＞年運＞命式内（月運は短い期間の目安）。

**日柱に巡る時期**
> 日柱は本人そのものと私生活を表す柱です。ここに天戦地冲が巡る時期は、暮らしの土台が大きく揺らぎやすくなります。夫婦・パートナーや家族との関係に区切りがつく、親しい人と離れる、住まいが変わるなど、望む・望まないにかかわらず身の回りが入れ替わる出来事が起こりやすい時期です。

**月柱に巡る時期**
> 月柱は仕事や社会での立場を表す柱です。ここに天戦地冲が巡る時期は、職場や仕事の状況が大きく動きやすくなります。異動や配置換え、勤め先の業績悪化や組織の再編、取引の打ち切り、思わぬトラブルでの信用低下などに注意が必要です。退職・転職・独立といった決断も重なりやすく、立場を落とすか、逆に大きく伸びるかの境目になります。

**向き**（大運＝{…}　年運＝{…}　月運＝{…} の後に続ける）
> ▶ 剋される側（外から壊される）：本人の望みとは別のところで、周囲や環境の側から圧力・試練が持ち込まれる形で起こりやすい。
> ▶ 剋す側（自分から壊す）：本人の言動がきっかけで、今の関係や状態を自ら崩してしまう形で起こりやすい。押し切る・独断で決めるといった強引さに注意。

**心身・備え・良い面**
> 心と体への負担も大きくなりやすい時期です。疲れやストレスの蓄積、気分の落ち込み、思いがけないケガや体調の崩れに気をつけてください。それまで当たり前だと思っていた考え方が通用しなくなり、気持ちが大きく揺さぶられることもあります。
> 備え：①大きな投資や事業の拡大、一か八かの勝負はこの時期を外し、今あるものを守る　②起きた変化を無理に元へ戻そうとしない（しがみつくほど傷が深くなる）　③休養と体調管理を予定に組み込み、無理を重ねない。
> なお、役目を終えた関係や合わなくなった環境に区切りをつけ、次の段階へ移るきっかけになる面もあります。

**命式内**
> 命式の中に天戦地冲がある人は、相反する気持ちを同時に抱えやすく、心の中で折り合いがつきにくい傾向があります。人生の起伏や試練も多くなりがちです（大運・年運で巡るときより影響は穏やか）。その反面、エネルギーが強く個性がはっきりしているため、自分のやり方を貫ける分野（表現・競技・独立した仕事など）では大きな力を発揮することがあります。
>
> 組ごと：「{柱}→日柱」（{干支}×{干支}）＝外（{領域}）から自分が剋される形。その領域から強い圧力や試練を受けやすく、内面の葛藤や消耗につながりやすい。／「日柱→{柱}」＝自分が外（{領域}）を剋す形。その領域と正面からぶつかり、関係を壊しやすい。強引さ・独断に注意。／「{柱}→{柱}」＝{領域}と{領域}の間で激しい衝突。2つの領域が両立しにくく、どちらかが崩れやすい。

**相性**
> 2人の柱の間に天戦地冲がある場合、相性としては刺激が強く、衝突の多い組み合わせとして注意します。最初は相手の自分と違う部分に強く引きつけられやすい一方、距離が縮まるにつれて、物事の判断基準や進め方、何を正しいと思うかの違いがはっきりし、言い争いやすれ違いが増えがちです。一緒にいるだけで互いの調子が崩れ、気疲れしやすい関係でもあります。（日柱どうしのときは「2人の核（日柱どうし）での天戦地冲は、この性質がいちばん強く出ます。」を続ける）
>
> 恋愛・夫婦：惹かれる気持ちと傷つく経験が繰り返されやすく、離れたりくっついたりを続ける関係になりがちです。相手の「普通」が自分の「普通」と大きく違うため、話し合いや歩み寄りに多くの労力がかかります。
> 仕事：目指す方向ややり方で意見が割れやすい組み合わせです。ただ、攻める役と守る役のように担当を分けられれば、片方だけでは出てこない発想や成果につながることもあります。
> 向き合い方：相手を自分の考えに合わせさせよう、思いどおりに動かそうとするほど、関係は決定的に壊れやすくなります。踏み込みすぎない距離を保ち、違いを相手の持ち味として認めることが、関係を続けるための前提です。すぐに離れるべき相性と決めつける必要はありませんが、手間のかかる関係であることは知っておきましょう。
>
> 向きの一文：本人が剋す側＝「本人の言動がお相手を押さえつけ、傷つけやすい形です。」／相手が剋す側＝「お相手からの圧力を本人が受け、ストレスをためやすい形です。」

詳細鑑定（文章生成）に渡す指示文は、上の内容を材料として渡し、「基本は凶・起こりやすい出来事を具体的に・断定しない・備えを必ず添える・良い面は最後に短く・凶を薄めない・剋の向きを区別する」を指示しています（実物は `pro/app-pro.html` の詳細鑑定データ部分）。
