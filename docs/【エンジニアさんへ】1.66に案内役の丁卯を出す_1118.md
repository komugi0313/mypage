開運予報の登録・ログイン・配信停止の画面に、案内役のうさぎ（4. 丁卯）をのせます（`【エンジニアさんへ】登録・ログイン・配信停止の色の直し_1118.md`）。
1.66からいきなり開運予報に移ると、別のサイトに来たように感じやすいです。なので、**1.66の側でも同じうさぎに先に出会ってもらい、開運予報までつながって見えるようにします**（オーナー決定）。

見本：`docs/見本_1.66に丁卯を出す3案.png` の **左（①）と右（③）**。まん中（②ポップアップに出す）は**入れません**。

**公開の順番：開運予報の色とイラストの直しと、同じ日に公開してください。** 1.66だけ先に出すと、「わたしがお届けします」と言っているのに、開運予報の画面にうさぎがいない形になります。

点数・相性の計算・回数の数え方・登録のしくみは、何も変えません。

## ③ 開運予報へ移るときの、つなぎの画面（1秒ほど）
- 1.66 から開運予報の**登録**へ移るとき（`a[data-kaireg]` のリンクを押したとき、結果の下のカードでメールを入れて「毎朝受け取る」を押したとき）に、画面いっぱいに出してから移ります。
- 出す時間は **0.9秒**。そのあと、今と同じリンク先（生年月日を「#」のうしろに付けたURL）へ移ります。
- 中身：丁卯（`guide-reg.webp`）、小さく「MY DAILY FORECAST」、大きく「私だけの開運予報へ／ご案内します」、小さく「1.66と同じ運営です・料金はかかりません」
- ブラウザの「戻る」で1.66に戻ったときに、この画面が残らないようにしてください（`pageshow` で消す）。
- 体験ページ（`data-kaidemo`）やログイン（右上の「ログイン」）には出しません。登録のときだけです。

JavaScript（`</body>` の前。**今ある「押した瞬間に最新の生年月日を付ける」クリックの処理（`document.addEventListener("click",…,true)`）より後ろ**に置いてください。そちらでリンク先が決まってから、この処理が動くようにするためです）：
```js
(function(){
  var ov=null,WAIT=900;
  function show(){
    if(!ov){ov=document.createElement("div");ov.id="kaiBridge";ov.setAttribute("role","status");
      ov.innerHTML='<img src="img/guide/guide-reg.webp" alt=""><div class="k1">MY DAILY FORECAST</div><div class="k2">私だけの開運予報へ<br>ご案内します</div><div class="k3">1.66と同じ運営です・料金はかかりません</div>';
      document.body.appendChild(ov);}
    ov.classList.add("on");
  }
  window.kaiBridgeGo=function(url){show();setTimeout(function(){location.href=url;},WAIT);};
  document.addEventListener("click",function(e){
    var a=e.target&&e.target.closest?e.target.closest("a[data-kaireg]"):null;
    if(!a||e.defaultPrevented||e.metaKey||e.ctrlKey||e.shiftKey||e.altKey||a.target==="_blank")return;
    e.preventDefault();window.kaiBridgeGo(a.href);
  });
  window.addEventListener("pageshow",function(){if(ov)ov.classList.remove("on");});
})();
```

結果の下のカードのメール欄（`#inlineMail`）の送信のところも、移り方をそろえます。今の
```js
location.href=kaiRegUrl(v);
```
を、次に置きかえてください。
```js
(window.kaiBridgeGo?window.kaiBridgeGo(kaiRegUrl(v)):location.href=kaiRegUrl(v));
```
