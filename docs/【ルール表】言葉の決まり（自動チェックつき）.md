# 言葉の決まり（自動チェックつき）

オーナーが決めた言葉のルールを1か所にまとめたものです。言い方を変えたら、**この表と `docs/ツール/check-kotoba.js` の両方にルールを足し**、直すたびに全部の画面とメールを自動で確かめます（取り残しをなくすため。10/12〜）。

確かめる範囲：ファイルの中の文字（画面には1日分しか出ない文の一覧も全部。注釈は除く）、2つのサイトの全ページ（広告動画ページ・見本ページ・規約も）の画面の文字、タップで開く説明の中、ページのタイトル・説明文・画像の説明、1.66 のシェア文、毎朝のメール（5つの状況×男女×12の誕生日×1年分、約11,000通）。
