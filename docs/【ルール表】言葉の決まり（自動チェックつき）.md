# 言葉の決まり（自動チェックつき）

オーナーが決めた言葉のルールを1か所にまとめたものです。言い方を変えたら、**この表と `docs/ツール/check-kotoba.js` の両方にルールを足し**、直すたびに全部の画面とメールを自動で確かめます（取り残しをなくすため。10/12〜）。

確かめる範囲：2つのサイトの全ページ（広告動画ページ・見本ページ・規約も）の画面の文字、タップで開く説明の中、ページのタイトル・説明文・画像の説明、1.66 のシェア文、毎朝のメール（5つの状況×男女×12の誕生日×1年分、約11,000通）。

## どこにも出さない言葉
| 使わない | 代わりに / 理由 |
|---|---|
| 無料 | 「料金はかかりません」だけ |
| 最強 | 「最高」 |
| 支配力 | 「リーダーシップ」 |
| 60組に1組・60組 | 冷めるので使わない（「1.66%」「めったに出ない」） |
| 晦気 | 専門用語 |
| 大殺界 | 別の占いの言葉（「別の占術です」という説明の中だけOK） |
| 特定商取引法に基づく表記・事業者情報 | 「運営者情報」 |
| 6時ごろ・6時頃 | 「6時」ちょうど（生まれた時刻を選ぶ欄の「◯時ごろ」はOK） |
| 運気予報 | 古いサービス名。今は「私だけの開運予報」 |
| 恋チャンス・モテ運UP・対人運UP・金運UP・💼 勝負日・仕事の気・金運の気・対人の気 | 今の印の名前（🌸恋が動く日・🌷出会い・モテ運の日・🌐対人運アップ・💰金運アップ・💼勝負運アップ） |
| ゆらぎ注意・空回り注意の日・大きく動く日・がんばりすぎ注意・無理しない日・「整える日」・ととのえの日・土台を整える日 | ⚠️注意の日（注意：強め／ふつう）・💡ひとこと・🐴動き・変化の日・ひかえめの日 |
| （印の名前ではないのでOK） | メールの「縁が大きく動く日。」（運命の人の日の一言）、「がんばりすぎ注意。意識して休憩を。」（体調の一言）は、ふつうの文として使っているので数えない |
| 絶好調日 | 「特別な日」「とても調子のいい日」 |
| 古い印 ⚡ 🌫️ 🌀 🔮（ページ） | ⚠️ 💡 🐴 |

## ふだんの画面には出さない（タップで開く説明の中はOK）
- 専門用語：天干・地支・命式・喜神・忌神・日柱・通変星・十神・律音・干合・支合・天戦地冲
- 干支の漢字（甲子など）。ただし、図鑑・1.66 の結果のタイプ札（読みがな付き）・マイページの生年月日の表は、キャラの名前として出しているのでOK
- 「天地徳合」は、近くに必ず「＝奇跡の縁」をつける（「『天地徳合』について知る」のボタンはOK）

## 人に合わせた言葉
- 恋人がいない人（恋人募集中・片想い）には、恋人がいる前提の文を出さない（交際中・パートナーがいる・二人の関係・マンネリ など）
- 恋人がいる人・結婚している人には、出会い向けの文を出さない（前から）
- 男性に女性向けの持ち物・行動を出さない、季節外れの料理を出さない、土日に仕事向けの一言を出さない（前から。メールの品質チェックで確認）

## 個人情報
- オーナーの名前・住所・生年月日は、どこにも出さない（「Produced by Mizuki Nico」だけOK）。ZIP を作るたびに自動で確かめる
