# 直すことの重さ分け（リリース前・リリース後）

10/12 オーナー決定。見つかったおかしなところは、まず「重さ」を決めてから直します。

## 重さの決め方
| 重さ | 中身 | いつ直すか |
|---|---|---|
| **致命的** | 運勢・干支の計算のまちがい／個人情報が出る／法律にかかわる／止まっていないのに「止まった」など誤解させる表示 | すぐ（リリース前に必ず） |
| **重要** | 読んだ人が困る・傷つく・「自分あてじゃない」と感じる言葉／オーナーが決めた言葉のルールに反する | リリース前に必ず |
| **軽い** | 見た目の数px／言い回しの好み／動きに影響しない小さなもの | この一覧にためて、リリース後にまとめて |

- 直したら毎回、**全部の自動チェック**をまわします（計算・メール・画面のエラー・はみ出し・言葉・ZIP）。言葉のルールは【ルール表】にまとめています。
- 最後に1回、総点検をして「ここで完成」と決めます。そのあとは致命的・重要だけを直します。
