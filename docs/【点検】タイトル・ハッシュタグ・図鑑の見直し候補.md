# タイトル・ハッシュタグ・図鑑の見直し候補（11月16日）

60タイプのタイトル・結果画面のハッシュタグ（14個）・図鑑（カードのタグ3つ・恋愛の欄・友だちの欄）を、
決定した恋愛の文と、オーナーが見せてくれた説明の文の共通点（決定記録に残したもの）と照らし合わせた。
**直す前に、かならず直し案を見せる。**

| 己亥 | 図鑑のタグ・恋愛の欄 | #ユーモアがある／相手を笑わせるのが大好き | 説明の文は「恋では本心を見せない・物静か」。ユーモアは説明の文にない |
