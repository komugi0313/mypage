# 【エンジニア向け】1.66相性診断：カレンダーに祝日を表示（2026-09-30・オーナー決定）

運気予報（unkiyoho.jp）のカレンダーと同じ表示を、1.66相性診断のカレンダー（マイページ・デモ画面）にも入れます。**2つの商品で同じタイミングで反映してください。**

## 何が変わるか（見た目だけ。運勢の計算・💮◎〇△・分野マークは一切変えない）
- 日付の数字：**日曜・祝日＝赤、土曜＝青**。曜日の見出し「日」「土」も同じ色
- 祝日の日は、数字の下に**小さく祝日名**（マス目用の短い名前：勤労感謝の日→「勤労感謝」、国民の休日→「休日」、スポーツの日→「スポーツ」、建国記念の日→「建国記念」、憲法記念日→「憲法記念」）
- 日付をタップしたときの見出しの横に「🎌 文化の日」（正式名）
- 祝日は `jp-holidays.js` が**自動で計算**（振替休日・国民の休日・春分／秋分の日を含む）。2025〜2027年の内閣府の発表と全日一致を確認済み。毎年の入れ直しは不要
