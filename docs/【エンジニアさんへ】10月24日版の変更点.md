## 4. 1.66 の回数の制限（ポップアップ）の動き（10/23 ブラウザで確認済み）

| 場合 | 結果 |
|---|---|
| 初めて開いた人 | 1〜4回目は診断できる。**5回目にポップアップ** |
| ポップアップが出た人が共有したリンク（`?ref=…`）を、友だちが開く | 友だちは**1〜4回目は診断できる**（すぐにポップアップは出ない）。5回目にポップアップ |
| ポップアップが出たあと登録して、完了画面の「1.66 相性診断にもどる」で戻った人 | 何回でも診断できる（8回まで試して、ポップアップは出ない） |
| 開運予報のマイページ・毎朝のメールのリンクから来た人（`?registered=1`） | 何回でも診断できる |
| 生年月日を入れずにボタンを押した | 回数に数えない |

- 回数と「登録済み」は、その人のブラウザに覚えます。`?registered=1` は開いたあとアドレス欄から消えるので、登録した人が共有しても、友だちが「登録済み」になることはありません。
- 注意：登録したあと、完了画面のボタンを使わずに、前に開いていた 1.66 の画面に自分で戻った場合は、まだ「登録済み」になっていません（サイトが別なので）。マイページか毎朝のメールの 1.66 へのリンクを一度通れば、それからはポップアップは出ません。

## 5. 登録した直後に、その日のメールを1通送る（10/24 新しくお願いすること）

登録してすぐに届けば「本当に届いた」と安心でき、迷惑メールに入ったときもその場で気づけるため、こう決まりました。

1. **送るとき**：登録が完了した瞬間（確認コードを入れて登録が終わったとき）。夜遅くでも、**その日（日本時間）の分**を送ります。
2. **作り方**：毎朝のメールと同じく `generateDaily()` → `renderDailyMail()` で作り、`renderDailyMail` に **`welcome: true`** を足すだけです。
   - 件名の始まりが「【ご登録ありがとうございます】」になります（ふだんは「【10/24(土)】」）。
   - あいさつが「〇〇さん、ご登録ありがとうございます」になります。
   - そのすぐ下に「今日の運勢を、さっそくお届けします。明日からは毎朝6時に届きます。」が入ります。
   - 朝のひとこと（「けさも…」）は出しません（夜に届いても変にならないように）。
   - 運勢・鑑定・ラッキーなどの中身は、ふだんのメールとまったく同じです。
   - `welcome` を付けないふだんのメールは、1文字も変わっていません（5人×366日＝1,830通で確認済み）。
3. **次の日から**：今までどおり毎朝6時に送ります。
4. **夜中0時〜朝6時に登録した人**：その朝6時のメールも送ってかまいません（オーナー確認）。最初の1通は件名の始まりが違うので、2通を見分けられます。
