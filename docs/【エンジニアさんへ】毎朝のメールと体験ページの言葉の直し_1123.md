10月4日の版のファイルを見て書いています。本番で同じ言葉が残っていたら、次のように直してください（もう直っているところは、そのままで大丈夫です）。

- デートの服の欄（カレンダーで日付をタップすると出る「💕 この日のおすすめデート服」）の見出しを、性別の言葉から服の雰囲気の言葉に変えました。「女性」→「ふんわりコーデ」、「男性」→「すっきりコーデ」。中の服（`DATEWEAR_F`・`DATEWEAR_M`）はそのままです。名前が長くなったので、`.dw-k` の幅を `flex:0 0 38px` から `flex:0 0 auto;white-space:nowrap` にしました。マイページでも同じ欄を出しているときは、同じように直してください。

- 本番の体験ページ・マイページで同じ言葉を使っているところがあれば、同じように直してください。
