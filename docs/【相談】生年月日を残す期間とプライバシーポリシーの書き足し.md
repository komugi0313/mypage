# 【相談】生年月日を残す期間と、プライバシーポリシーの書き足し（11月17日）

みんなの相性表とバースデー帳を作ると、今まではスマホの中だけで使っていた生年月日を、サーバーに送ることになります。
そのため、次の2つを決める必要があります。

1. サーバーに、どれくらいの期間残すか
2. プライバシーポリシー（kaiunyoho.com/privacy.html）に、何を書き足すか

**残す期間は、11/17 オーナー決定で「24時間」。ポリシーの書き足しは、この案で進める予定（公開前に最終確認）。**

---

## 1. 残す期間（案）

| 何を | どこに | 残す期間（案） |
|---|---|---|
| グループ（みんなの相性表）の参加者のニックネーム・生年月日・タイプ・相性 | サーバー | 作ってから **24時間** で自動で消す（11/17 オーナー決定） |
| 「生年月日をみんなに見せない」を選んだ人の生年月日 | ― | **サーバーに送らない**（スマホの中でタイプに変えて、タイプだけ送る） |
| 登録していない人のバースデー帳 | そのスマホの中だけ | 本人が消すまで（サーバーには送らない） |
| 登録した人のバースデー帳（保存した人と、保存した相性表） | サーバー | 本人が消すか、登録を削除するまで |
| 参加の入口（LINEのリンク・QRの4けたの番号） | サーバー | 10分（決定ずみ） |

### 24時間に決めた理由
- 長く残すほど、生年月日が漏れたときの心配が大きくなるので、いちばん短い24時間にする（オーナー決定）。
- 残したい人は、バースデー帳に保存すればずっと残せる。

---

## 2. プライバシーポリシーへの書き足し（案）

今のポリシーの最初に「『1.66 奇跡の相性診断』で入力する生年月日は、お使いの端末の中で計算に使うだけで、当社のサーバーには送信・保存しません。」とあります。
みんなの相性表とバースデー帳を始めると、この一文と合わなくなるので、**必ず直す必要があります。**

### 2-1. 最初の段落（直す）
- 今：なお、「1.66 奇跡の相性診断」で入力する生年月日は、お使いの端末の中で計算に使うだけで、当社のサーバーには送信・保存しません。
- 案：なお、「1.66 奇跡の相性診断」の二人の相性診断で入力する生年月日は、お使いの端末の中で計算に使うだけで、当社のサーバーには送信・保存しません。「みんなの相性表」と、ご登録の方の「バースデー帳」をお使いになるときだけ、下記のとおりサーバーに送信・保存します。

### 2-2. 「1. 取得する情報」に足す
- **みんなの相性表の情報**：参加された方のニックネーム、生年月日、タイプ、参加者どうしの相性の結果。「生年月日をみんなに見せない」を選んだ方の生年月日は、端末の中でタイプに変えて、タイプだけを送信します（生年月日そのものは送信しません）。
- **バースデー帳の情報（ご登録の方のみ）**：保存した方のニックネーム、生年月日、タイプ、相性の結果、保存した相性表。ご登録のない方のバースデー帳は、お使いの端末の中だけに保存し、当社のサーバーには送信しません。

### 2-3. 「2. 利用目的」に足す
- みんなの相性表の表示（参加者どうしの相性の計算と、参加者への表示）
- バースデー帳の保存・表示（ご登録の方が、機種変更などのあとも見られるようにするため）

### 2-4. 「5. 保管期間」に足す
- みんなの相性表の情報は、作成から24時間で自動的に消去します。
- バースデー帳の情報は、ご本人が消去するか、登録を削除するまで保管します。登録を削除すると、バースデー帳の情報もすべて消去します。

### 2-5. 「6. 未成年者の情報とデータ最小化」に足す
- みんなの相性表とバースデー帳の生年月日・ニックネームは、広告の配信・最適化には使いません。

### 2-6. 「7. 開示・訂正・削除のご請求」に足す
- みんなの相性表で、ご自身の生年月日を見せたくなくなったときは、「生年月日をみんなに見せない」にいつでも切りかえられます。
- ほかの方のバースデー帳に保存されたご自身の情報の削除をご希望の場合は、下記お問い合わせ先までご連絡ください。

### 2-7. 最終改定日
- 書き足したら、最終改定日を新しい日付にします。

## 3. 気をつけたいこと
- **ほかの人の生年月日を残すこと**：みんなの相性表に参加した人は、自分で生年月日を入れて「見せる」を選んでいるので、本人が見せることに同意しています。ただし、バースデー帳に手で書きこむ人（グループに参加していない人）は、本人の同意がありません。利用規約に「ご本人に断ってから書きこんでください」と一言入れるのがおすすめです。
- **参加する画面での表示**：参加ボタンの近くに「参加すると、プライバシーポリシーに同意したものとします」と、小さくリンクを入れるのがおすすめです。
- 法律の細かい判断が必要な場合は、専門家に確認してください。
