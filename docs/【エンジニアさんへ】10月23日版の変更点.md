## 4. 1.66 の回数の制限（ポップアップ）の動き（10/23 ブラウザで確認済み）

| 場合 | 結果 |
|---|---|
| 初めて開いた人 | 1〜4回目は診断できる。**5回目にポップアップ** |
| ポップアップが出た人が共有したリンク（`?ref=…`）を、友だちが開く | 友だちは**1〜4回目は診断できる**（すぐにポップアップは出ない）。5回目にポップアップ |
| ポップアップが出たあと登録して、完了画面の「1.66 相性診断にもどる」で戻った人 | 何回でも診断できる（8回まで試して、ポップアップは出ない） |
| 開運予報のマイページ・毎朝のメールのリンクから来た人（`?registered=1`） | 何回でも診断できる |
| 生年月日を入れずにボタンを押した | 回数に数えない |

- 回数と「登録済み」は、その人のブラウザに覚えます。`?registered=1` は開いたあとアドレス欄から消えるので、登録した人が共有しても、友だちが「登録済み」になることはありません。
- 注意：登録したあと、完了画面のボタンを使わずに、前に開いていた 1.66 の画面に自分で戻った場合は、まだ「登録済み」になっていません（サイトが別なので）。マイページか毎朝のメールの 1.66 へのリンクを一度通れば、それからはポップアップは出ません。
