# 恋のかたち診断（koi16）― はじめにお読みください

無料の恋愛タイプ診断（40問・16タイプ）です。四柱推命は使いません。集客の入口として、結果の下から「1.66 奇跡の相性診断」（https://166unmei.com/）へ案内します。
PRO・ビギナー・易とは**別の商品**です（引き渡しのときも混ぜない）。

## 1. 中身

| ファイル | 役割 |
|---|---|
| `index.html` | 診断の画面すべて（はじめ・質問・結果・16タイプ一覧・この診断の考え方）。ビルド不要。1ファイルで動きます |
| `og-image.png` | SNSでシェアしたときの画像 |
| `functions/koi16-collect.js` | 答えを**名前なしで**集める受け口（研究への協力を選んだ人だけ） |
| `functions/koi16-export.js` | 集まった答えを、運営者だけが取り出す口（合言葉つき） |
| `netlify.toml`・`package.json` | 関数の場所と、データ置き場（`@netlify/blobs`）の指定 |

## 2. 公開のしかた（Netlify）

1. このフォルダ `koi16/` をそのまま Netlify のサイトにします（公開するフォルダ＝`koi16/`、関数＝`functions/`）。
2. 環境変数（Site settings → Environment variables）を入れます。

| 名前 | 必須 | 中身 |
|---|---|---|
| `KOI16_SALT` | 必須 | 連打よけのハッシュに混ぜる、長いランダムな文字列 |
| `KOI16_OWNER_TOKEN` | 必須 | 答えを取り出すときの合言葉（長いランダムな文字列。運営者だけが知る） |
| `KOI16_MAX_IP_DAY` | 任意 | 同じ通信元から1日に受け取る件数の上限（既定 20） |
| `ALLOWED_ORIGINS` | 任意 | 自サイト以外に許可する送信元（独自ドメインと netlify.app を両方使うときなど。カンマ区切り） |

3. 画面は `/.netlify/functions/koi16-collect` に答えを送ります。Netlify 以外で動かすときは、この道すじに同じ働きの受け口を置いてください。

## 3. 集める答えと守ること

- **保存するもの**：質問の版（`q2`）・本格版／かんたん版・今の恋の状況・40問の答え（−2〜2、かんたん版で聞いていない問いは null）・年代と性別（選んだときだけ）・出たタイプ・日付（日まで）。
- **保存しないもの**：名前・メール・IPアドレス・端末の情報・時刻。連打よけにIPを使いますが、日ごとに変わるハッシュで回数だけを数え、答えとは結びつけません。
- **送らない・受け取らないもの**：チェックを外した人の答え／18歳未満を選んだ人の答え／ほかのサイトからの送信／中身のおかしい答え。
- 画面の説明（はじめの画面・ページの下・「この診断の考え方」）と食いちがわないようにしてください。保存するものを増やすときは、画面の説明も直します。

## 4. 答えの取り出しと確かめ

```bash
curl -H "x-koi16-owner: 合言葉" https://（サイトのURL）/.netlify/functions/koi16-export -o koi16_answers.json
```

```bash
python3 tools/koi16_analyze.py koi16_answers.json > koi16_report.md
```

`koi16_report.md` に、ものさしごとの信頼性（α）・うまく働いていない質問・16タイプのかたより・不安と頼り方の関係・男女差などが出ます。本格版が200件未満のうちは参考程度です。

## 5. 点検

```bash
node tools/release_gate/gate_koi16.cjs
```

```bash
node tools/release_gate/gate_koi16_collect.cjs
```

1つ目はスマホの幅6種類で泣き別れ・はみ出し・小さいボタンが0件か、2つ目は答えの受け口と取り出し口が決まりどおりに動くかを確かめます。

## 6. 質問を変えるとき

`index.html` の `QS`（40問）を変えたら、`index.html` の `QV` と `functions/koi16-collect.js` の `QV` を同じ値に上げてください（例：`q2` → `q3`）。古い版の答えと混ざらないようにするためです。
