# Pocket鑑定 発売前チェックと課金の進め方（2026-09-26）

## 1. 今回テストして直したこと

### AIの会話（実際の Gemini・10言語）
10言語それぞれで1つの長い会話をしました。質問は16個で、次のものを含みます。
- 恋愛・転職・お金・健康・家族・今日の運勢
- お礼、同じ質問の2回目、「もっと詳しく」
- 関係ない質問（晩ごはん）、落ち込み、相性（相手の誕生日）、性格の短所、来月の運勢
- 英語での質問、「消えたい」という深刻な相談

| 見つかった問題 | 直したこと |
|---|---|
| 相手の誕生日を書いて相性を聞くと、日本語以外の9言語で「あなたの誕生日は○年○月○日ですね」という決まり文句が返っていた | 日付を含む文は「自分の誕生日の質問」と扱わないようにした |
| スペイン語・ポルトガル語・インドネシア語・タイ語・ベトナム語の日付の書き方（「3 de mayo de 1990」「3 Mei 1990」「3 พฤษภาคม 2533」「3/5/1990」など）を相手の誕生日として読めず、相性の計算が動いていなかった | 10言語の日付の書き方に対応した（タイの仏暦も） |
| 中国語で「你们的你的特质」という崩れた文が出ていた | 置き換えを修正した |
| 深刻な相談で、スペイン語なら全員にスペインの窓口、英語なら全員に米国の窓口が出ていた | 端末の地域を見て、その国の窓口を出すようにした（メキシコ・英国・カナダ・豪州・フィリピン・香港・ポルトガルなど26か国）。一覧にない国は「地域の緊急番号へ」とだけ案内する |
| 決まり文句が「端末の中だけに保存」と言っていた（アカウント導入後は事実と違う） | ログイン中はこの注記を出さない |
| スペイン語・ポルトガル語の決まり文句が、男性にも女性形で話していた | 性別に合わせるようにした |
| 相性の返事で、AIが相手の誕生日を「あなたの誕生日」と取り違えていた（スペイン語・タイ語で「お二人とも1990年5月3日生まれ」、ベトナム語で本人の誕生日を聞き返す） | AIに渡すデータに「本人の生年月日」と「相手の生年月日（本人ではない）」を明記した |
| 相手の性別（彼・彼女）を、日本語・英語・韓国語・中国語でしか読み取れていなかった | 10言語の「彼氏・夫・novio・anh ấy・suami・แฟนหนุ่ม」などに対応した |
| ベトナム語で、前の返事の段落を丸ごと写して付け足すことがあった | 前の返事と同じ段落は自動で取り除くようにした |

- **同じ言葉のくり返し：** 前と同じ文、またはほぼ同じ文は、10言語で合計2件でした。どちらも「つらい話への『お気持ちお察しします』」のような自然な重なりです。3回以上出る決まり文句もほとんどありません。
- **別の言語の混入：** 0件です。
- **エラー・返事なし：** 0件です。
- **最終確認について：** 最後の修正（相性の取り違え・相手の性別・段落の写し）のあと、実際の AI での再確認をしようとしたところ、**テスト用 API キーの前払いクレジットが残っていない**という応答が返り、実行できませんでした。AI に渡すデータに正しく入ることと、単体テストは確認済みです。発売前に、クレジットを追加したキーで相性の質問を各言語で一度ずつ試してください（`tests/live.js` の手順）。

## 2. 発売前に必ず必要なこと（未完成）

### 2-1. 課金（App Store / Google Play）が、まだ実装されていません
今あるのは、料金の説明画面と、開発者用の「テスト用プラン切替」だけです。購入ボタン・購入の確認・解約の案内はありません。

**安全のために、今回サーバー側をこう変えました：**
- アプリが名乗るプラン名（`x-pk-plan`）は誰でも書き換えられます。そこで、課金を実装するまでは信用せず、**全員を無料枠（1日5回）として扱います。**
- テストで有料枠を試す時だけ、環境変数 `PK_TRUST_PLAN_HEADER=1` を設定してください。
- あわせて、アプリとサーバーのプラン名のずれを直しました。以前はスタンダード（`std`）と使い放題（`unl`）をサーバーが知らず、無料枠（1日5回）扱いになっていました。

**App Store / Google Play で売るために必要な作業：**
1. **アプリ化：** 今のWebアプリ（PWA）を、Capacitor などで iOS / Android のアプリにします。
   - Apple は「Webサイトをそのまま包んだだけのアプリ」を審査で落とすことがあります（ガイドライン4.2）。通知などアプリならではの機能を入れておくと安全です。
2. **ストアでの商品登録：** App Store Connect と Google Play Console に、3つの月額プラン（おてがる・スタンダード・使い放題）を登録します。価格は国ごとにストアで設定します。
3. **購入の仕組み：** RevenueCat などの課金サービスを使うと、iOS と Android の両方をまとめて扱えます。購入した人のプランは、ストアから届く通知をもとにサーバー（アカウント）に記録します。
4. **チャットのサーバーを直す：** プランは、アプリの自己申告ではなく「アカウントに記録されたプラン」で判定します。
5. **料金画面を直す：**
   - 購入ボタン
   - **「購入を復元」ボタン**（Apple の必須要件）
   - 解約方法の案内
   - 自動更新の説明と、利用規約・プライバシーポリシーへのリンク（Apple の必須要件）
   - 価格は、ストアから受け取った各国の価格を表示する（今の画面は円・ドル・ウォンなどを直接書いています）
   - 「お支払いはクレジットカード」という文言を、「App Store / Google Play のアカウントで支払い」に変更（料金画面とマイページ、10言語）
6. **ストアの申請書類：** Apple のプライバシー表示（どんなデータを集めるか）、Google の「データセーフティ」、審査用のテストアカウント、スクリーンショット（言語ごと）。
