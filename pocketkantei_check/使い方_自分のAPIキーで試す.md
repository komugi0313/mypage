# 自分の Gemini API キーで試す（テスト用サイト）

`Netlify用_テストサイト.zip` は、サーバーなしで動くテスト版です。Gemini の API キーを画面に貼ると、Nico と話せます。

## 手順
1. `Netlify用_テストサイト.zip` を展開し、中身をいつもどおり Netlify に置きます（前のサイトに上書きでかまいません）。
2. スマホかパソコンで、そのサイトを開きます。
   - 前に開いたことがある端末は、古い画面が残っていることがあります。表示がおかしい時は、ページを2回読み込み直してください（今の版は `v208`）。
3. 「はじめる」→ 名前・生年月日・性別 → 確認のチェック → 登録。
   - テスト用サイトにはログインのサーバーがないので、メール登録は飛ばして中に入ります。
4. アンケートに答えます（メールは何でもかまいません）。
5. チャット画面の上に「テスト版：Gemini の API キー」の欄が出ます。キーを貼って「使う」を押します。
   - 入力したキーは「●●●」で隠れます。キーは、その端末のブラウザの中だけに保存されます（サーバーや他の人には送られません。AI を呼ぶ時に Google にだけ送られます）。
   - 自分のキーで動かしている間は、回数の上限はありません（使った分だけ Google から請求されます）。
6. 話しかけます。
   - 「点検表示：オン」にすると、Nico の返事の下に、使ったモデルや「必ず触れる項目」が入ったかが小さく出ます（確認用）。
   - キーを替える時は「変更」。

## 試すとよいこと
`会話テスト/テスト6項目/結果.md` の6項目（性格・なぜ？・来年・健康・金運／来月・転職・「2026年でもいい？」／「当たってない」・宝くじ・AIなの？／返金・解約・パスワード・あと何回／DV・消えたい・17歳／相づち・韓国語・繁体字・英語）。

## 注意
- テスト用サイトの URL を、ほかの人に広めないでください（キーを貼れる画面が出ます）。
- 試し終わったら「変更」でキーを消すか、ブラウザのデータを消してください。
- 本番（Firebase）では、この欄は出ません。
