> この ZIP は、**全商品が共通でつなぐサーバー（会員・決済・詳細鑑定の中継・回数上限）**の依頼書と、画面を作り直すための開発用ツールです。今後リリースする商品（toC・toB、Web とアプリ）も、すべてこの同じ基盤につなぎます。

## 入っているもの
| ファイル | 内容 |
|---|---|
| `エンジニアへの実装依頼_3サイト.md` | **最初に読む**依頼書（サーバーで作るもの・決済・メール・回数上限・本番切替・受け入れ確認） |
| `実装仕様_会員まわり_共通.md` | 会員・決済・API の詳しい仕様（共通基盤。§11 が今後の商品・アプリ版の設計） |
| `CLAUDE.md` | このリポジトリの絶対ルール（計算エンジンを触らない等） |
| `tools/` | 画面を作り直す開発用ツール（ビギナー・易の申込画面を PRO から生成、文字の見えやすさの安全装置、商品の目印 `X-Product` の埋め込み） |
| `meishiki-original/` | 個人版（販売しない）。鑑定書 `meishi-sheet.html` を各商品とバイト単位で同じに保つための元 |

## 画面を直すときの順番（開発用。3つの商品 ZIP を同じ場所に展開して行う）
1. `python3 tools/add_contrast_guard.py`
2. `python3 tools/sync_beginner_from_pro.py`（PRO → ビギナー）
3. `python3 tools/eki_pay_from_pro.py eki-pro`（PRO → 易の申込・ログイン・マイページ）
4. `python3 tools/add_product_tag.py`（各ページに商品ID `pro`／`beginner`／`eki` を入れ直す）
5. 変えた商品の `sw.js` の `CACHE` を上げ、本番切替（各商品の「はじめにお読みください」）をやり直す
