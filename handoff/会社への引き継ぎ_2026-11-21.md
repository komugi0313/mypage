## 3. 点検のやり方と費用

点検の道具は `tools/release_gate/` にあります（使い方は同じフォルダの `README.md`）。**費用がかかるのは「通信あり（online）」の点検だけ**です。

**料金のかからない点検**（文章作成を呼ばない。直すたびに毎回回す）：

```
node tools/release_gate/gate_pk.mjs pro offline      # PRO（通信できないとき）
node tools/release_gate/gate_pk.mjs beginner offline
node tools/release_gate/gate_pk.mjs pro nonet        # 圏外
node tools/release_gate/gate_pk.mjs beginner nonet
node tools/release_gate/gate_eki.mjs offline
node tools/release_gate/gate_eki.mjs nonet
node tools/release_gate/gate_compat_rules.mjs pro    # 流派の決まり・表（1マスずつ）
node tools/release_gate/gate_compat_rules.mjs beginner
node tools/release_gate/gate_kuu.mjs                 # 空亡
node tools/release_gate/gate_neardate.mjs            # 近い日の質問
node tools/release_gate/gate_ygz.mjs                 # 年の干支
node tools/release_gate/gate_facts.mjs --selftest    # 事実の点検の点検
```

2026-11-21 時点で、上はすべて合格です（PRO・ビギナー 88/88、易 41/41、決まりの表 ちがい0）。

**料金のかかる点検**（文章作成を呼ぶ。販売の前に一度だけ・大きな直しのあとだけ）：

```
GEMINI_API_KEY=… node tools/release_gate/gate_pk.mjs pro online        # 約8回の呼び出し
GEMINI_API_KEY=… node tools/release_gate/gate_pk.mjs beginner online   # 約8〜10回
GEMINI_API_KEY=… node tools/release_gate/gate_eki.mjs online           # 約6回
GEMINI_API_KEY=… node tools/release_gate/gate_compat.mjs pro           # 約2回
GEMINI_API_KEY=… node tools/release_gate/gate_facts.mjs --fresh        # 30件版
GEMINI_API_KEY=… node tools/release_gate/gate_facts.mjs --fresh --size full   # 320件版（いちばん多い。販売前に1回）
```

- 合格の目安：上の全部が合格、`gate_facts` の320件でまちがい0（2026-11-19 の時点では0）。
- 鍵は環境変数でだけ渡し、画面・記録・ファイルに出さない。
