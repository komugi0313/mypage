# 「相手が答えたら、メールでお知らせ（任意）」のつなぎ方（エンジニアの方へ）

対象：無料の3サイト（恋のかたち診断 `koi16/`・究極の二択 `nitaku/`・アイシンク `isync/`）
作った日：2026-11-22（鑑定者本人の指示「UIに形だけつけたい。これから共通の会員基盤のサーバーにつなぐ」）

## いまの状態

- 画面の欄（見出し「お相手が答えたら、メールでお知らせ」・「10日以内に答えたときだけ届きます」・メールアドレスと「登録」）だけがあります。同意のチェックは入れていません（お知らせだけのメールで、広告を入れないため）。
- 受け口（`endpoint`）が `null` のあいだは、入れたメールアドレスを**どこにも送らず、端末にも残しません**。押すと「準備中です」と出るだけです。
- 元のファイルは `tools/notify_email.js` です。`python3 tools/add_notify_email.py` を回すと、3つのサイトの `index.html` の `<!--NOTIFY-MAIL:start-->`〜`end` に埋め込まれます。

## つなぐ手順

1. `tools/add_notify_email.py` の `SITES` で、各サイトの4つ目の値（`None`）を受け口のURLに変えます（例：`'https://api.example.jp/notify'`）。
2. `python3 tools/add_notify_email.py` を回します。これで本当に送るようになります。
3. プライバシーポリシーの「メールでのお知らせ（任意）」は書いてあります（2026-11-22）。「送り先：このサイトの運営者のサーバー」を、実際のサーバーとメールを送る会社の名前に直してください（`tools/free_privacy.py`、恋のかたち診断は `koi16/index.html` の `renderPrivacy`）。改定日も上げます。
4. 送り主（サイト名・問い合わせ先 info@72k.ai）と「お知らせを止める」リンクを、メールの文面に入れます。お知らせだけのメールにし、広告（ほかのサービスの案内など）は入れません。広告を入れると特定電子メール法の同意の取り方が必要になります。
5. **つないでから公開します**（鑑定者本人の方針。つなぐ前のまま公開しない）。

## 画面から受け口に送るもの（POST・JSON）

```
登録（リンクを送った人）
{ "type":"subscribe", "site":"isync|nitaku|koi16", "kind":"with|invite",
  "ref":"リンクの目印", "email":"...", "days":10, "at":1763800000000 }

答えた（リンクを開いて答え終わった人のスマホから）
{ "type":"answered", "site":"...", "kind":"...", "ref":"リンクの目印", "name":"ニックネーム（10文字まで）", "at":... }
```

- 受け口は、`ref` が同じ登録があれば、その人に「○○さんが答えました」のメールを送ります。
- 返事は 2xx なら成功です（画面は「登録しました」と出します）。それ以外は「うまく登録できませんでした」と出します。
- 登録は `days`（10日）で消してください。部屋・答え合わせのリンクが使える期間と同じです。
- いたずら対策として、同じ `ref` へのメールの回数制限や、同じアドレスへの1日の上限を入れてください。

## `ref`（リンクの目印）の決め方

| サイト | どこの欄 | 目印 |
|---|---|---|
| アイシンク | ひとりの結果の「次は、この○問で答え合わせ」の下 | 答え合わせのリンクの id（12文字。届く答え合わせ `isync_inbox` と同じ id） |
| 究極の二択 | ひとりの結果の「この○問で、だれかと答え合わせ」の下 | `PkNotify.refOf(リンクの答えの部分)`。答えた人のスマホでも同じ文字列から同じ目印になります |
| 恋のかたち診断 | 自分の結果の「結果をシェア・相手にも送る」の下 | この端末の送り主の印 `st.nid`（10文字）。登録したときだけ、送るリンクに `&n=印` が付きます（つながるまではリンクは変わりません） |

答えた人の側の呼び出し：

- アイシンク：`isync/app.js` の `inboxSend(...)` の直後
- 究極の二択：`showWithResult()` の中
- 恋のかたち診断：`finish()` の中（`?from=` と `&n=` で来た人が診断を終えたとき）

## まだしていないこと（つなぐときに決める）

- 3つのサイトの「部屋」のリンク（10日間あとから参加できる）にも同じ欄を付けるか
- メールアドレスの確認メール（ダブルオプトイン）を入れるか
