## 1. 決済・料金（PRO・ビギナーと同じ）

- **料金は月額 9,800円（税込）のみ・7日間無料**（お申し込み日を1日目とする7日間。8日目に初回課金、以後毎月その日。その日がない月は月末日）。お一人様1回。
- **お支払いはクレジットカードのみ**（決済代行：テレコムクレジット株式会社）。銀行振込・PayPay 等は使わない。
- 無料期間・継続課金・カード変更・解約・結果通知の具体的なやり方は、**テレコムクレジットの接続仕様書で確認**（共通仕様 §4）。
- **無料期間の終わりのお知らせはしない**（発注者決定 2026-10-13）：終了前のお知らせメールも、アプリ内の最終日の案内も**ありません**。代わりに「何日まで無料で、何日から自動で月額9,800円になるか」を、申込の確認画面・完了画面・マイページ・特商法に日付で明記しています。パスワード設定メールにも同じ日付を書いてください。
- **二重申込は自動で取り消さない**・**無料体験の2回目は赤字で知らせるだけ**（申し込みは止めない）。詳しくは共通仕様 §3-4・§3-5・§4-2。

## 2. 画面の流れ（実装済み）

```
LP（index.html）
  └ 申込ボタン → register.html（お名前・メール2回・任意のプロフィール・同意）
        └ apply-start に {email, profile} を送る（返事は待たない・失敗しても進む）
        └ upgrade.html（お申し込み内容の最終確認＝特商法。register で入れたメールで自動的に確認画面へ）
              └「この内容で申し込む（決済ページへ）」→ テレコムクレジットの決済ページ（カード登録）
                    └ 決済結果の通知（サーバー間）→ サーバーが会員を作成（trialing）→ パスワード設定メール
                    └ 戻り先 upgrade.html?result=ok（完了画面）／?result=ng（中断・失敗。back も同じ）
                          └ auth.html でパスワード設定 → ログイン → app/index.html（鑑定ツール）
マイページ mypage.html：契約状況・カード変更・メールアドレス変更・解約・困ったとき（アプリの⚙設定・LPのフッターからリンク）
```

1. `register.html`：お名前（必須）・メール**2回入力**（不一致はエラー）・任意のプロフィール（性別・年代・都道府県・職業・占い経験）・規約／特商法／プライバシー／自動更新への同意 → `apply-start` に `{ email, profile:{ name, sex, age, pref, job, exp } }` を送る（`CONFIG.STUB` が true の間は送らない）→ `upgrade.html`。メールは `eki_apply`（1時間有効）で受け渡す。`register.html` は手で管理（生成しない）。
2. `upgrade.html`（PRO から `tools/eki_pay_from_pro.py eki-pro` で生成。**直接編集しない**）：最終確認（メール・料金・無料期間の終了日・初回課金日・更新日・解約期限・ご利用の上限〈1日の上限なし・月の利用枠を使い切ってもオフライン鑑定で続けられる・無料期間中は1日3回〉・解約と返金）→ お申し込み番号（`E-YYYYMMDD-XXXXX-XXXXX`）とメールを付けて `TELECOM_PAYMENT_URL` へ（パラメータ名は `TELECOM_PARAM`）。URL が空の間は「準備中」と表示して進まない。
3. **会員は決済結果の通知で作る**（戻り先URLの表示だけで作らない）。`apply-start` で控えたプロフィールとは**メールでひも付ける**（申込前はお申し込み番号がまだ無い）。
4. `auth.html`・`mypage.html` も PRO から生成。API は共通仕様 §3 のとおり（EKI は顧客カルテ同期 `mypage-get`／`mypage-put` を**使わない**）。
5. **会員ゲート**は `app/index.html` の先頭に実装済み（ログイン → `auth-login`、以後 `auth-check`。使える状態のときだけ開く）。`var PREVIEW_MODE = true;`（660行）を本番で `false` に。本番ドメイン（`72k.ai`・`suimei.jp`・`ekipro.jp`）では書き忘れても自動で `false` になる（662行）。30日以内にログインを確認した端末は圏外でも開く（`OFFLINE_DAYS=30`）。ロック中も顧客名簿を書き出せる（`#mg-export`）。
6. `register.html` の「▶ 登録せずに、そのまま鑑定を体験する（デモ）」リンク（`#demoLink`）は、`file:`／`localhost`／`127.0.0.1` のときだけ表示される。本番では出ないが、公開前に削除する。

## 3. 無料お試しの回数と、無料体験の2回目（★サーバー連携が必要）

### 3-1. 回数
- **無料期間中（`status=trialing`）のオンライン鑑定は1日3回まで**（鑑定＋深掘り相談の合計。日本時間の暦日で0に戻す）。
  - フロント：`isTrialMember()`（1333行。`localStorage.member_status==='trialing'`）のときだけ `TRIAL_DAILY_LIMIT=3`（1334行）で日ごとに数える（`eki_trial_YYYYMMDD`）。有料（`active` 等）は回数を数えない（サーバーが費用で見て、届いた月だけ 429 `MONTH_BUDGET`）。
  - 上限に達しても**鑑定は止めない**：その日は内蔵データでの鑑定に切り替え、`#trialLimit`「本日の無料お試し（オンライン鑑定）を使い切りました／…内蔵データでの鑑定はそのまま使えます。オンライン鑑定は明日また使えます。」＋「ご契約内容を見る（マイページ）」を表示。深掘り相談は上限のお知らせをチャット欄に出す。
  - **端末の数字は消せば戻るので、サーバーでも会員ごとに数えて上限をかける**（`gemini` 中継で。共通仕様 §3-3）。
- **有料の上限**：**回数では数えない・1日の上限なし**（発注者決定 2026-10-17）。サーバーが1人あたりの実際の費用をご契約の期間ごとに足し、月2,940円（月額9,800円−手数料5%−利益65%）に届いたら次の更新日まで 429 `MONTH_BUDGET` → 画面は内蔵データの鑑定に切替（`paidReached()` 1362行・「鑑定する」の下 `#ekiLeft` に「今月はお休み中」）。お客様への表示は「1日の上限なし」「月の利用枠を使い切っても、次の更新日までオフライン鑑定で続けられる」だけ（件数の目安は出さない）。追加の利用枠の販売はしない。くわしくは `実装仕様_会員まわり_共通.md` §3-3。＋**1分15回**の連打制限（非公表。規約 第8条の「頻度に上限」が根拠）。`PAID_RATE_PER_MIN=15`（1387行）は定義だけ＝**サーバーで実装する**。
- **数え方＝鑑定1件で1回**：
  - 鑑定1件は**サーバー呼び出し2回**（①答えだけ ②台本・要点などの残り）。②には **`x-eki-kind: detail`** が付く → **数えない**。
  - 鑑定書の作成（**`x-eki-kind: sho`**）→ **数えない**（鑑定に付随するため）。専門用語が残ったときは1回だけ作り直す（2回目も `sho`）。
  - 深掘り相談は1問＝1回（目印なし）。
  - 画面側も同じ数え方（鑑定1件ごとに1回、深掘り1問ごとに1回）。
- AI を使わない機能（立卦・内蔵データの鑑定・顧客名簿・印刷）は無制限。

### 3-2. 無料体験はお一人様1回（ゆるく運用）
- 申込の確認画面（`upgrade.html`）で、そのメールアドレスに以前の申込の記録があれば、赤字で「⚠ 無料体験は、お一人様1回までです。このメールアドレスでは、以前にお申し込みいただいた記録があります。」と表示する（端末の記録と `trial-check` で判定。実装済み）。**申し込みは止めない**。
- 2回目（同一メール・同一カード）と分かっても、**自動で取り消したり、無料なしで即時に課金したりはしない**（7日分の重複利用は許容。発注者決定 2026-10-13）。同一カードを判定できる値がテレコムクレジットで取れるなら記録して、`trial-check` に使う。

## 4. オンライン鑑定（`gemini` 中継）

- 呼び出し先：`'/.netlify/functions/gemini'`（3106行に直接記述。`netlify.toml` で `/api/gemini` も同じ関数）。雛形 `functions/gemini.js`（PRO と同じ仕組み）。キーはサーバーの `GEMINI_API_KEY` だけ。
- ヘッダ：`Authorization: Bearer <member_token>`、`x-pk-device`（端末の識別子 `eki_dev`）、目印 `x-eki-kind: detail`／`sho`（上記）。
- body：`{ contents:[{ parts:[{ text }] }], generationConfig:{ maxOutputTokens:4096, temperature:0.8, thinkingConfig:{ thinkingBudget:0 } } }`（`system_instruction` は使わない。モデル名は送らない）。`thinkingBudget:0` は思考トークンの課金を防ぐコスト対策（雛形も flash 系では必ず0にする）。
- フロントの待ち方：70秒で打ち切り。混雑（429・503 等）や通信エラーは最大2回まで再試行。だめなら**内蔵データの鑑定に自動で切り替え**。401＝「ログインの有効期限が切れました」、403＝「ご契約の状態を確認できませんでした。マイページで…」。
- 返ってきた文章はフロントで、`*`・`＊` を消し（`/[＊*]/g`）、「AI」の言い回しと読みの誤り（てんいつきじん→てんおつきじん、ぎょうざい／きょうざい→ごうざい）を直し（`noAIWord`）、お名前の印〔お名前〕を本当のお名前に戻す（`fillName`）。**お名前は外部に送らない**。
- **テスト用キー**：`#demoKeyCard`（鑑定タブ・840行）と `#geminiCard`（設定タブ・1120行）は、http(s) では URL に `?gtest=1` を付けたときだけ表示（3422行）。保存したキー（`eki_pro_key`）も `?gtest=1` のとき（またはファイルを直接開いたとき）だけ使い、本番のURLでは必ずサーバー中継を通る（2026-10-13 修正）。**公開前に2つの欄と3422行を削除**（欄を消してもアプリが止まらないことを確認済み）。1322行の `GEMINI_API_KEY = ""` は空のまま（ここにキーを書かない）。

### 4-1. 鑑定の作り方（答えを先に出す2回呼び出し）
1. 1回目：「▼判定・▼伝え方・▼助言 の3つだけ」を作り、届いたらすぐ表示（「作成中」の印 `ekiPending`）。
2. 2回目：1回目の答えを【先に作成した答え】として渡し、残り（台本・要点・裏卦など）を作る（`x-eki-kind: detail`）。1回目に出した判定・伝え方・助言は上書きしない。
3. 終わったら回数を1回数える（`trialInc()`）。

### 4-2. 費用の目安（要再計測）
- 以前の実測（1回呼び出しだった時期・`gemini-2.5-flash`・入力 $0.30／出力 $2.50 per 1M）：鑑定1回 約¥0.57、深掘り1問 約¥0.14。
- **今は鑑定1件で2回呼び出す**ため、上の数字より高くなる。本番前に、雛形の原価ログ（`[pro-cost]`・応答ヘッダ `x-pk-tok`）で**鑑定1件あたり（2回分）を測り直す**。
- 有料の上限（費用で月2,940円）は、使い切る人がいても利益65%を守るための線。既定のモデルは `gemini-3.5-flash-lite`（思考は minimal）。モデルや単価を変えたら `x-pk-tok` で1件の費用を測り直し。

## 5. 鑑定の中身（フロント完結・サーバー移植は不要）

- **立卦**：4方式（コイン式〈自動〉・手動で指定・数字で立てる・カード）。どれも同じ卦の計算に合流。
- **計算**（純JS・コスト0・オフライン可）：`TG`（八卦）、`HEXDB`（64卦の卦名・読み・卦辞・爻辞など。**書きかえ禁止**）、`HEXKK`（吉凶ランク）、`calcGoka`（互卦）、`calcShika`（之卦）、`calcSoka`（綜卦）、`calcSakka`（錯卦）、`buildResult()`、`buildPrompt()`、`parseReading()`。
- **命式（任意）**：相談者の生年月日（＋時刻）があれば、`calcPillars` が**四柱推命PROと同じ計算エンジン（`window.Bazi.computeChart`）**で年柱・月柱・日柱（時柱）を出す（エンジンが読めないときだけ簡易計算で代用）。使い方：深掘り相談では本文を易だけで完結させ、必要なときだけ末尾に「――生まれ持った性質から：」の一〜二文を添える。鑑定書では④⑤に使う。鑑定本体（1回目・2回目）の指示には入れない。**空亡は参考表示のみで、文章生成には渡さない**（年運を断定しない方針）。
- **言葉づかいの方針**：アプリの画面・台本・要点・深掘り相談では、卦の名前・卦辞・爻辞の**原文を正確に**示し、必ず「現代語にすると〜」を添える（`MODERN64`・`TAI_FIX`）。**お客様にお渡しする鑑定書だけ**は専門用語なしの現代語（取りこぼしは `plainEki()` で置きかえ）。
- **相談の入口**：鑑定タブの「何を占いますか？」カード（`#cs-box`・866行。文言は i18n の `c2_consult`・`c2_consult_sub`）。画面だけの機能。

## 6. 端末に保存するデータ（サーバーには保存しない）

- **顧客名簿と設定は端末内だけ**（`localStorage['eki_pro_v1']`）。**規約 第12条・プライバシーポリシー・登録画面で「当社のサーバーには保存しません」と約束している**ので、サーバーに移すなら、先に規約・プライバシーポリシーの改訂が必要（発注者と相談）。
- 形（読み込み時に `cleanDb` が検査。決まった形以外は捨てる）：
```jsonc
{
  "settings": { "brand":"屋号〜60字", "name":"鑑定士名〜60字", "role":"肩書き〜60字", "logo":"印の文字1〜2字",
                "shoTitle":"鑑定書の題字〜12字", "contact":"連絡先〜300字", "accent":"#8E72A8（#RRGGBB）" },
  "customers": [ { "id":"英数_-1〜64字", "name":"〜100字", "kana":"〜40字", "memo":"〜20000字",
                   "history": [ { "at":0, "hex":"卦名", "no":1, "ko":"爻", "shika":"之卦", "q":"相談〜4000字",
                                  "script":"台本〜40000字", "topic":"英数〜32字", "memo":"〜8000字",
                                  "hantei":"判定〜600字", "tsutae":"伝え方〜6000字", "jogen":"助言〜3000字", "rank":"A〜E", "off":true,
                                  "rd":{ "結論などの各項目":"〜8000字" }, "chat":[ { "role":"user|ai", "text":"〜6000字" } ] } ] } ],
  "recent": [ /* お客様を選ばずに行った鑑定（history と同じ形・新しい順に30件まで） */ ]
}
```
- **鑑定は自動保存**（2026-10-17〜）：鑑定が出たとき・くわしい読み解きが届いたとき・チャットの返事ごと・メモの入力で、選んでいるお客様の `history` に自動で入る（判定・伝え方・助言・各項目・チャット直近10往復も保存）。お客様を選んでいないときは `recent`（「最近の鑑定（お客様未選択）」・30件）に入り、「お客様に移す」で名簿の履歴へ移せる。顧客タブの各履歴の「📖 この鑑定を見る」で中身を見返せる（以前の形式の記録も、ある分だけ表示）。
- ⚙設定でできること：屋号・鑑定士名・肩書き・印の文字・鑑定書の題字・連絡先・色、バックアップ（書き出し・読み込み）、「データの消去」、「ご契約・ログイン」（マイページ・パスワードの変更・お困りのとき・規約類・ログアウト）。料金の設定は無い。
- そのほかのキー：`member_email`・`member_token`・`member_status`・`member_period_end`・`member_checked_at`（会員）、`eki_trial_YYYYMMDD`（その日の回数）、`eki_dev`（端末の識別子）、`eki_apply`・`pending_order`・`selected_plan`・`trial_used`（申込）、`eki_pro_key`（テスト用キー）。

## 11. 用語（エンジニア向け最低限）

- **本卦（ほんか）**：占ってまず立つ、今の状況を表す卦（64種）。
- **変爻（へんこう）**：6本の爻のうち動く1本。今の注目点。
- **之卦（しか）**：変爻が動いた先の卦＝この先の展開。`#shikaBox` に表示。
- **互卦（ごか）**：本卦の内側に隠れた卦＝背景・本音。裏卦欄に薄紫。
- **綜卦（そうか）**：本卦を上下ひっくり返した卦＝相手の立場から見た状況。裏卦欄に青。
- **錯卦（さくか）**：本卦の陰陽をすべて反転した卦＝正反対の可能性。裏卦欄に茶。
- **卦辞／爻辞（かじ／こうじ）**：古典の言葉。画面では原文＋現代語。
- **立卦（りっか）**：卦を立てること。
- **命式（めいしき）**：生年月日から立てる四柱推命の年柱・月柱・日柱（＋時柱）。易の「土台」として添える。
- **空亡（くうぼう）**：日柱の干支が属する旬から余る2支。参考表示のみ（文章生成には渡さない）。
