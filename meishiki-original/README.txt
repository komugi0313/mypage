命式作成ソフト（最新版）— Netlifyデプロイ手順

このZIPには、AI鑑定（Gemini）を「ずっと内蔵」で動かすための一式が入っています。
・index.html … 命式作成ソフト本体
・pro-bazi.js / pro-adapter.js … 計算エンジン
・functions/gemini.js … AI鑑定のサーバー窓口（APIキーをブラウザに出さないための仕組み）
・package.json / netlify.toml … Netlify用の設定

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【いちばん大事なこと：APIキーは“サイトのファイル”に書かない】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
キーをHTML等に直接書くと、第三者に盗まれて“あなたのGoogleアカウントに
無制限に課金”される危険があります。
そこで、キーは Netlify の「環境変数」に1回だけ登録します。
こうすると、キーはサーバー側に隠れたまま、サイト上ではAI鑑定が
“誰もキーを入力せず・自動で・ずっと”動きます。これが安全な「内蔵」です。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順1】このフォルダをNetlifyにデプロイ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Netlifyにログイン →「命式作成ソフト」用のサイトを開く
   （Pocket鑑定/みんかれ 等の別サイトと間違えないこと）
2. このフォルダ（またはZIP）を Deploys にドラッグ＆ドロップ
3. index.html＝命式作成ソフトが表示されます

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【手順2】GeminiのAPIキーをNetlifyに1回だけ登録（★これで“内蔵”完了）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Google AI Studio（aistudio.google.com）でGemini APIキーを取得
   （「Get API key」→ 表示された AIza… で始まる文字列をコピー）
2. Netlify → 対象サイト → Site configuration →
   Environment variables →「Add a variable」
3. Key（名前）に：  GEMINI_API_KEY
   Value（値）に：   コピーしたAPIキー（AIza…）
   を入力して保存
4. Deploys →「Trigger deploy → Deploy site」で再デプロイ
   （環境変数は再デプロイで反映されます）
→ 以降、サイトを開けばAI鑑定が“キー入力なしで自動”で動きます。

■確認方法：サイトを開き「AI鑑定の設定」の上に
  「✅ AI鑑定：このサイトで自動で使えます」と緑で出ていればOK。
  もしAIが動かない時は、GEMINI_API_KEY の綴り・値・再デプロイを見直してください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【任意】自分だけ“回数上限なし”にしたい場合
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・環境変数 PK_OWNER_TOKEN に、自分だけが知る合言葉を登録
・アプリの「AI鑑定の設定 →オーナー合言葉」に同じ文字列を入れる
→ あなたの端末だけ回数上限なしでAI鑑定が使えます（他の人は通常の上限）。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【豆知識】使うモデル・上限・料金の目安を変えたい時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
functions/gemini.js が読む環境変数で調整できます（任意）：
  GEMINI_MODEL        … 軽い鑑定/雑談のモデル（既定 gemini-2.5-flash-lite）
  GEMINI_MODEL_DEEP   … 本格鑑定のモデル（既定 gemini-3.6-flash）
  PK_OWNER_TOKEN      … 自分専用・上限なしの合言葉
※通常はGEMINI_API_KEYだけ設定すれば動きます。

【ビルドエラーが出る等でAI無しでも良い場合の代替】
・meishiki.html を index.html にリネームして置くだけでも命式は表示されます
  （functions と package.json を使わない＝AI鑑定は無効・ビルド不要）
