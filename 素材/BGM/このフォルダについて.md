# 紹介動画のBGM（元の音源）

紹介ページのデモ動画に使っている音楽の元ファイルです。動画を撮り直すときに、また使えるように保管しています。

- `PRO紹介動画のBGM（元の音源・2026-07）.m4a` … 四柱推命PROの紹介動画（`pro/demo.mp4`・`pro/demo.webm`）のBGM。2026-07 の旧動画から取り出したもの
- `ビギナー紹介動画のBGM（元の音源・2026-07）.m4a` … 今日から占い師の紹介動画（`beginner/demo.mp4`）のBGM
- `易EKI_Pro紹介動画のBGM（神秘的・アップテンポ・このために作った音楽・2026-10）.m4a` … 易 EKI Pro の紹介動画（`eki-pro/demo.mp4`）とSNS用ショート動画のBGM。発注者の希望「神秘的だけどアップテンポ」で作り直した曲（ニ短調・和声的短音階・124BPM。きらめくベルとアルペジオ、4つ打ちのリズム）。この動画のためにプログラムで合成した音楽で、他の人の曲・音源は使っていない（広告にも使える）。約95秒（静かな出だし→盛り上がり→中間の静かな部分→盛り上がり→フェードアウト）

動画のほうが長いときは、曲の終わりと始まりを重ねてつなぎ、最後をフェードアウトしています。
