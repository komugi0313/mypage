利用規約

本規約は、72k株式会社（以下「当社」）が提供する「四柱推命占い自動鑑定 PRO」（以下「本サービス」）の利用条件を定めるものです。ご利用の前に必ずお読みください。

第1条（適用）

本規約は、本サービスの提供条件および当社と利用者との間の権利義務関係を定めるものであり、利用者と当社との間の本サービスの利用に関わる一切に適用されます。お申し込みまたはご利用をもって、本規約に同意したものとみなします。

第2条（定義）

  1. 「利用者」：本サービスを利用するすべての方。
  2. 「会員」：お申し込みを行い、本サービスの利用契約を結んだ利用者。
  3. 「鑑定コンテンツ」：生年月日・ご相談内容等の入力にもとづき本サービスが作成する四柱推命の鑑定結果・鑑定文・鑑定書などの情報。
  4. 「相談者」：会員が本サービスを使って鑑定を行う相手の方（会員のお客様等）。

第3条（お申し込み・アカウント）

  1. 利用者は、当社所定の方法によりメールアドレス等を登録し、お支払い方法（クレジットカード）を登録してお申し込みを行います。
  2. 登録情報は正確かつ最新の内容を提供するものとします。
  3. アカウントおよびログイン情報の管理は利用者の責任とし、第三者への貸与・共有・譲渡はできません。
  4. 未成年者は、親権者等法定代理人の同意を得たうえでご利用ください。
  5. 同一の方が重複してお申し込みされた場合も、各契約はそれぞれ有効に成立します。不要な契約は、会員ご自身でマイページから解約してください。無料期間の終了後に発生した料金は、重複によるものであっても返金いたしません。

第4条（料金・支払い）

  1. 本サービスは月額プラン（月額9,800円・税込）により提供します。料金の詳細は特定商取引法に基づく表記に定めるとおりです。
  2. 料金は、登録されたクレジットカードにより決済されます。決済は決済代行会社（テレコムクレジット株式会社）を通じて行われ、当社はカード番号を保持しません。
  3. 契約は毎月の更新日に自動的に更新され、更新日に次の1か月分の料金が課金されます。更新日にあたる日がない月は、その月の末日を更新日とします。
  4. 料金のお支払いが確認できない場合、当社は本サービスの提供を停止することがあります。

第5条（無料お試し期間）

  1. 無料お試し期間は、お申し込み日を1日目とする7日間です。無料期間中は料金は発生しません。
  2. 無料期間中に解約しなかった場合、8日目に月額プランへ自動的に移行し、初回の料金（9,800円・税込）が課金されます。以後、その日が毎月の更新日となります。
  3. 無料お試し期間中、詳細鑑定（オンラインでの鑑定文の作成。相談・鑑定書の作成などの合計）のご利用は、1日あたり3回までとします（日本時間の0時に戻ります）。端末内の鑑定・命式表・顧客カルテ等、詳細鑑定を伴わない機能に回数制限はありません。
  4. 無料お試し期間は、お一人様1回限りです。メールアドレスの変更・複数登録・再登録その他の方法により無料お試し期間を繰り返し取得することはできません。当社がこれに該当すると判断した場合、無料お試し期間を付与しないことがあります。

第6条（解約・返金）

  1. 会員は、マイページからいつでも解約できます。無料期間中に解約された場合、料金は一切発生しません。
  2. 解約された場合も、無料期間またはお支払い済みの期間の最終日までは、引き続き本サービスをご利用いただけます。次回の更新日からの請求は停止します。次回の請求を止めるには、更新日の前日の23時59分（日本時間）までに解約の手続きを完了してください。
  3. 当社のシステム障害等によりマイページから解約できない場合は、info@72k.ai へのメールで解約を承ります。この場合、当社がメールを受信した日を解約日として扱います。
  4. デジタルサービスの性質上、お支払い済みの期間の途中で解約された場合の返金・日割りの返金はいたしません（第9条第2項・第4項の場合を除きます）。

第7条（鑑定コンテンツの利用）

  1. 会員は、鑑定コンテンツを、ご自身の鑑定業務（対面・電話・オンラインでの鑑定、鑑定書の作成・お渡し・送付、有料での鑑定を含みます）において、相談者に提供・販売することができます。
  2. 会員が相談者の氏名・生年月日・ご相談内容等を本サービスに入力する場合は、会員の責任において、相談者から必要な同意を得るものとします。
  3. 前2項にかかわらず、本サービス（ツール）そのものの複製・転売・再販売、アカウントの共有・貸与、本サービスの画面や文章をまとめて第三者のサービスに組み込むことはできません。

第8条（禁止事項・公正利用）

利用者は、以下の行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 当社または第三者の権利・利益を侵害する行為
  3. 本サービスの複製・改変・リバースエンジニアリング
  4. 不正アクセス、自動化ツール・スクリプト等による利用、サーバーに過度の負荷をかける行為、運営を妨げる行為
  5. アカウントの不正利用・なりすまし、無料お試し期間の不正な繰り返し取得
  6. 鑑定結果を、他者の不利益・差別・断定的な決めつけ・不安をあおる高額な勧誘に用いる行為

詳細鑑定（オンラインでの鑑定文の作成）に、1日あたりの回数の上限はありません（無料お試し期間中の回数は、前述の無料お試しの定めによります）。サービスの安定運用のため、1か月（更新日から次の更新日の前日まで）の利用枠（月額料金でまかなえる範囲）を使い切った場合は、次の更新日までオフラインの詳細鑑定（端末内で作成する鑑定）に切り替わります。この間も鑑定は続けてご利用いただけます。切り替えによる月額料金の減額・返金はなく、利用枠の追加販売も行っていません。このほか、上記に該当する行為や、通常の利用を著しく超える利用（自動化・アカウントの共有・転売等を含みます）を確認した場合、当社は公正な利用のため、そのアカウントのご利用を一時的に制限し、または回数・頻度に上限を設けることがあります。

第9条（本サービスの変更・中断・終了）

  1. 当社は、システムの保守・障害・天災その他やむを得ない事由がある場合、事前の通知なく本サービスの提供を一時的に中断することがあります。

  3. 当社は、本サービスの内容を変更することがあります。会員に重要な影響がある変更は、事前に本サイト等でお知らせします。
  4. 当社の責めに帰すべき事由（当社のシステム障害等）により、本サービスを連続して48時間以上ご利用いただけなかった場合、当社は、お支払い済みの期間のうちご利用いただけなかった日数分の料金を日割りで返金します。会員は、info@72k.ai へご連絡ください（第1項の保守による一時的な中断、および会員の通信環境・端末・外部サービスの障害による場合を除きます）。
